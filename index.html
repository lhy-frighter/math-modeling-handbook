01评价决策模型

任务形态：给若干对象打分、排名、分级、选优。国赛最稳妥的拿分题型，闭环是"指标正向化 → 定权重 → 合成得分 → 敏感性分析"。下面每个算法点开都有公式、适用场景、建模步骤和易错点。
出现频率：极高难度 ★★常与规划/统计组合
指标正向化与无量纲化第 0 步必做▾把成本型、区间型等不同方向、不同量纲的指标统一成"越大越好且可比"的标准矩阵，是所有评价法的前置。
核心公式
极小型→极大型：x′=max(x)−x 或 x′=1/x；中间型：x′=1−|x−x*|/max|x−x*|；区间型：区间内取 1，区间外按距离衰减
向量规范（TOPSIS 用）：zᵢⱼ=xᵢⱼ/√(Σᵢxᵢⱼ²)；min-max 归一（熵权用）：z=(x−min)/(max−min)，归到 [0,0.99] 防 ln0
应用场景
  • 指标方向不一致：效益（越大越好）与成本（越小越好）混在一起，如产值与污染
  • 量纲差异大：金额（万元）与百分比、评分（百分制）混在一起不能直接加权
建模步骤
  1. 逐列判断指标类型（极大/极小/中间/区间）并列表说明
  2. 按公式正向化，全部转为极大型
  3. 按后续方法选标准化方式（TOPSIS 向量规范、熵权 min-max）
  4. 论文中给出处理前后的矩阵片段对照
要点与易错
  • 不做正向化直接加权，会出现"成本越高得分越高"的方向性错误
  • 有训练/测试划分时，归一参数只能用训练集统计量，否则信息泄漏
层次分析法 AHP主观赋权高频▾用 1-9 标度做两两比较，把专家经验转成权重，适合含定性指标、缺历史数据的评价。
核心公式
判断矩阵 A 满足 aᵢⱼ·aⱼᵢ=1；权重≈A 最大特征值 λmax 对应特征向量归一化
一致性：CI=(λmax−n)/(n−1)，CR=CI/RI < 0.1 才通过；RI(n=3..9)=0.52,0.89,1.12,1.26,1.36,1.41,1.46
应用场景
  • 含安全性、满意度、重要程度等定性判断，无客观数据支撑权重
  • 指标天然分层（目标层-准则层-方案层）的方案选优
建模步骤
  1. 画层次结构图（论文必配），同层指标两两比较
  2. 按 1-9 标度填正互反判断矩阵
  3. 算术平均、几何平均、特征值法三种求权重，优秀论文取三者平均
  4. 算 CI、CR 做一致性检验，不通过就调整矩阵
  5. 逐层加权汇总成方案总分并排序，权重 ±10% 做敏感性分析
要点与易错
  • 指标超过 9 个时一致性很难达标，先分层再比较
  • 选择依据写法："体系含定性指标、缺大样本数据，AHP 可把经验结构化并用 CR 保证逻辑自洽"
熵权法客观赋权高频▾某指标在对象间差异越大、信息熵越小，区分能力越强、权重越高，权重完全由数据决定。
核心公式
比重 pᵢⱼ=zᵢⱼ/Σᵢzᵢⱼ → 熵 eⱼ=−Σᵢpᵢⱼln pᵢⱼ/ln n → 差异系数 dⱼ=1−eⱼ → 权重 wⱼ=dⱼ/Σd
应用场景
  • 所有对象都有完整数据、且不希望掺入主观偏好
  • 与 AHP 组合：主观经验 + 客观数据互相校正
建模步骤
  1. min-max 归一到 [0,0.99]（避免 ln0）
  2. 逐列算比重、信息熵、差异系数
  3. 归一化差异系数得客观权重
要点与易错
  • 优秀论文实例（海底数据中心散热选材）：以导热率、抗压、抗腐蚀、价格四指标，先剔除不适用于海水环境的材料，再用熵权打分，最高分为 AISI 1040 钢，并算出可承受 654.8m 水深压力，是"先筛后评"的标准动作
  • 所有对象某指标取值几乎相同时，熵权会给极小权重，这是合理的（无区分度），论文要解释
CRITIC 权重法客观赋权中频▾在熵权之外同时考虑指标对比强度和指标间冲突（相关性），指标高度相关时比熵权更合理，属论文亮点。
核心公式
信息量 Cⱼ=σⱼ·Σᵢ(1−rᵢⱼ)，σⱼ 为第 j 列标准差，rᵢⱼ 为指标 i、j 的相关系数；wⱼ=Cⱼ/ΣC
应用场景
  • 指标之间存在明显相关、不希望重复计权
  • 想比熵权法多体现"波动性"和"冲突性"时作为对比方法
建模步骤
  1. 无量纲化后算各列标准差 σ
  2. 算指标相关系数矩阵 R
  3. 逐列求 Cⱼ 并归一化得权重
要点与易错
  • 相关系数方向：正相关越强冲突越小，(1−r) 越小，正好实现"重复信息降权"。
TOPSIS 优劣解距离法综合排序高频▾构造正、负理想解，对象离正理想越近、离负理想越远越优，是最常用的综合排名方法。
核心公式
D⁺=√Σwⱼ(zᵢⱼ−z⁺ⱼ)²，D⁻=√Σwⱼ(zᵢⱼ−z⁻ⱼ)²；得分 S=D⁻/(D⁺+D⁻)∈[0,1]，越大越优
应用场景
  • 多个对象、多个指标，需要给出综合排名（供应商、城市、方案、选址）
  • 权重来自 AHP/熵权/CRITIC，TOPSIS 只负责距离排序
建模步骤
  1. 正向化 + 向量规范得标准矩阵
  2. 每列乘权重 w（组合赋权结果）
  3. 列方向取最大为正理想 Z⁺、最小为负理想 Z⁻
  4. 逐行算 D⁺、D⁻、得分 S 并排序
要点与易错
  • TOPSIS 本身不产生权重，必须交代权重来源
  • 高分范式："组合赋权-加权 TOPSIS"，并用灰色关联或换权重做交叉验证
灰色关联分析小样本中频▾样本少、数据灰度大时，比较各序列与理想序列的几何贴近程度，也能分析各因素影响大小。
核心公式
关联系数 ξᵢ(k)=[min|x₀−xᵢ|+ρmax|x₀−xᵢ|]/[|x₀(k)−xᵢ(k)|+ρmax|x₀−xᵢ|]；关联度 rᵢ=均值 ξ，ρ 为分辨系数常取 0.5
应用场景
  • 只有几个到十几个样本，做综合评价或方案对标
  • 因素分析：母序列（如 GDP）受哪些子序列（各产业）影响最大
建模步骤
  1. 确定参考（理想）序列，全部序列无量纲化
  2. 算两级最小差、最大差
  3. 逐点算关联系数再平均得关联度，按关联度排序
要点与易错
  • 分辨系数 ρ 取 0.5 是惯例，应对 ρ∈[0.3,0.7] 做敏感性分析看排序是否稳定。
模糊综合评价等级模糊中频▾当评价等级边界模糊（优/良/中/差）时，用隶属度矩阵把"程度"量化后加权定级。
核心公式
因素集 U、评语集 V；隶属度矩阵 R（每行是一个因素对各等级的隶属度，行和为 1）；综合向量 B=W∘R，按最大隶属度或加权得分定级
应用场景
  • 水质/空气质量分级、安全风险、满意度、教学质量等"等级型"评价
  • 数据来自专家打分或问卷比例时
建模步骤
  1. 建因素集与评语集，AHP/熵权求因素权重 W
  2. 用隶属函数（三角/梯形）或投票比例构造 R
  3. 选合成算子（推荐加权平均 M(·,+)，信息损失小）算 B
  4. 最大隶属度定级，或给各等级赋分算综合得分
要点与易错
  • 避免用取大取小算子（主因素决定型），它会丢掉大量信息；隶属函数选择要说明依据。
DEA 数据包络分析多投入多产出中频▾评价同类决策单元相对效率，无需预设权重，每个单元解一个线性规划，效率值 1 即有效。
核心公式
CCR：max (uᵀy₀)/(vᵀx₀) s.t. 所有单元 uᵀyⱼ/(vᵀxⱼ)≤1（Charnes-Cooper 转线性规划）；BCC 加入凸性约束 Σλ=1，可拆出纯技术效率与规模效率
应用场景
  • 评价医院、银行分行、产区、高校等同类单位的投入产出效率
  • 指标都是"投入（越少越好）+ 产出（越多越好）"且无法定权重
建模步骤
  1. 确定决策单元 DMU（数量建议 ≥ 2(投入数+产出数)）
  2. 选投入、产出指标（非负、量纲不影响结果）
  3. 逐个 DMU 解 CCR/BCC 线性规划得效率值与松弛变量
  4. 效率=1 为 DEA 有效，否则给出投入冗余/产出不足的改进方向
要点与易错
  • 指标数过多会导致几乎所有单元都"有效"，要精简指标；效率是相对值，只在样本内可比。

组合赋权（高分写法）与方法选择

主观权重反映经验、客观权重反映数据：乘法合成 wⱼ=(w主·w客)/Σ(w主·w客)，放大两者一致认可的指标；线性组合 w=αw主+(1−α)w客，α 取 0.5 并对 α 做敏感性分析；博弈论组合赋权极小化权重偏差属亮点。

方法权重来源数据要求典型场景
AHP主观可无数据定性指标、分层方案选优
熵权/CRITIC客观全样本数据无先验偏好、数据驱动
TOPSIS外接权重指标齐全多对象综合排名
灰色关联外接权重小样本序列对标序列、因素分析
模糊综合主观隶属函数等级边界模糊
DEA无需权重多投入多产出同类单位相对效率
证据链要求：评价结果出来后必须做敏感性分析（扰动权重或分辨系数看排名是否稳定）+ 至少一种方法交叉验证（如 TOPSIS 与灰色关联排名对比），只给一个排名表属于"验证缺失"。

MODULE 02 · OPTIMIZATION

02数学规划模型

优化类是国赛出现最多的题型。统一用四步法建模：决策变量 → 目标函数 → 约束条件 → 变量域，再按线性/非线性、连续/离散、单/多目标选求解器。点开每张卡看公式、场景、步骤与求解代码入口。
出现频率：最高难度 ★★★常与启发式/评价组合

优化建模四步法（论文照此展开）

  1. 决策变量：哪些量"我能决定"，用 x₁,x₂,… 表示，说清连续/整数/0-1 属性
  2. 目标函数：把要最优的目标写成 f(x)，多目标时说明权衡关系
  3. 约束条件：资源、逻辑、守恒写成 s.t. g(x)≤0、h(x)=0，每条注明现实来源
  4. 变量域：xᵢ≥0、xᵢ∈{0,1}、整数约束、上下界
证据链：求解后逐项核验约束是否满足（优秀论文仅 18.6% 做到），并与贪心/原方案等基线比较目标值改善幅度。
线性规划 LP连续线性高频▾目标和约束全是线性表达式，是配料、运输、排班、资源分配问题的标准模型，必有全局最优。
核心公式
max/min Z=cᵀx　s.t. Ax≤b，Aeq·x=beq，lb≤x≤ub
应用场景
  • 配料/混合问题：原料配比使成本最低且满足成分要求
  • 运输/指派：产地到销地调运、任务分配使总费用最小
  • 生产计划、资源分配：有限资源下最大化利润
建模步骤
  1. 设决策变量（运输量、产量等，注明非负）
  2. 把目标写成变量的线性组合
  3. 逐类资源写 ≤ 约束，平衡关系写 = 约束，下限写界
  4. scipy.linprog（小）/ pulp、Gurobi（中大）求解，报告最优值与影子价格
要点与易错
  • 对偶问题的影子价格=资源边际价值，写进讨论是加分点
  • 注意 linprog 默认只求最小值，最大化取负号；约束方向别写反
非线性规划 NLP连续非线性高频▾目标或约束含乘积、平方、超越函数，用 SLSQP/内点法求解，非凸时要多初值防局部最优。
核心公式
min f(x)　s.t. gᵢ(x)≤0，hⱼ(x)=0，lb≤x≤ub；KKT 条件为最优性一阶必要条件
应用场景
  • 曲线拟合/参数反演：最小二乘 min Σ(y−f(x;θ))²（curve_fit）
  • 几何优化、曲面设计、含规模经济（成本非线性）的生产问题
建模步骤
  1. 判断凸性：凸函数+凸集才有全局最优保证
  2. scipy.optimize.minimize(method='SLSQP') 同时给等式/不等式约束
  3. 非凸问题从多个初值出发取最优，或改用 GA/PSO
  4. 报告收敛状态、迭代次数与最优值
要点与易错
  • 只跑一个初值就声称"最优"是常见硬伤；等式约束要用 'eq' 类型
  • 能线性化就线性化（变量替换），线性规划比 NLP 稳得多
整数规划与 0-1 规划（含大 M 法）离散决策高频▾变量必须取整数或 0/1，用于选址、指派、背包、排班、路径，用分支定界精确求解。
核心公式
同 LP，但 x∈ℤ 或 x∈{0,1}；大 M 法：y=1 时约束生效写成 Ax≤b+M(1−y)，M 取足够大常数
应用场景
  • 设施选址（建/不建）、选课/投资组合（选/不选）、车辆路径
  • 固定成本问题：启用才发生费用；互斥、多选一等逻辑约束
建模步骤
  1. 连续量设普通变量，离散决策设 0-1 变量 y
  2. 用大 M 法把"如果…才…"翻译成线性不等式
  3. 互斥 Σyᵢ=1、至少选 k 个 Σyᵢ≥k、启用才计费 成本≥K·y 且 x≤M·y
  4. Gurobi/ortools 分支定界求解；规模过大转启发式
要点与易错
  • M 要"足够大但不夸张"，过大会数值不稳定，按约束上界估计
  • 整数变量不能用 LP 解完四舍五入，结果可能不可行或非最优
动态规划 DP多阶段决策中频▾把问题拆成有序阶段，用状态转移方程递推求解，前提是最优子结构与无后效性。
核心公式
最优性方程：fₖ(s)=opt{ 阶段收益 + fₖ₊₁(s′) }，s 为状态，s′=T(s,a) 为转移后的状态
应用场景
  • 最短路径、背包、库存与生产批量、资源分配、设备更新
  • 决策按时间或阶段顺序展开且当前决策只依赖当前状态
建模步骤
  1. 划分阶段，定义状态 s（含全部相关历史信息）
  2. 写决策变量与状态转移方程
  3. 建立指标函数与边界条件
  4. 逆序（或顺序）递推求最优值，再正向回溯最优策略
要点与易错
  • 状态维数超过 3 会"维数灾"，此时改用启发式；状态定义必须保证无后效性。
多目标规划目标冲突高频▾多个互相冲突的目标（成本低 vs 服务好），转化为单目标或求 Pareto 前沿后再折中决策。
核心公式
线性加权 max Σwₖfₖ（先归一）；ε-约束：max f₁ s.t. fₖ≥εₖ；理想点：min √Σwₖ(fₖ−fₖ*)²；Pareto：不存在支配解
应用场景
  • 供应链：成本、时效、稳定性同时优化（2021C 三目标）
  • 调度：效率与公平、收益与风险的平衡
建模步骤
  1. 列出各目标并分别归一化去量纲
  2. 选转化方式：加权（权重来自 m1）/ ε-约束 / 理想点
  3. 要一组折中方案时用 NSGA-II（pymoo）求 Pareto 前沿
  4. 用决策准则（TOPSIS/拐点）从前沿选最终解，并对权重做敏感性
要点与易错
  • 目标不归一直接加权会被量纲大的目标主导；只给一个权重结果不做敏感性，结论不稳。
博弈论与纳什均衡策略对抗中频▾多个决策者的收益互相影响时，求"谁都不愿单独改变策略"的均衡，用于定价补贴、竞标、资源争夺、对抗类题目。
核心公式
参与人 i 的收益 uᵢ(sᵢ, s₋ᵢ)；纳什均衡：uᵢ(sᵢ*, s₋ᵢ*) ≥ uᵢ(sᵢ, s₋ᵢ*) 对所有策略 sᵢ 成立（给定他人策略，自己改不会更好）
零和博弈用最小最大 maxmin；无纯策略均衡时求混合策略：以概率 p 选择行动，使对方选任一行动收益相等；合作博弈用 Shapley 值分配联盟收益
应用场景
  • 多方策略对抗：如 2020B 穿越沙漠中玩家对资源与路线的竞争、平台-司机-乘客的补贴定价、排队/竞标策略
  • 合作收益分配：多方协作后按边际贡献（Shapley 值）分摊收益或成本
  • 与优化结合：在对手最优反应下求己方最优行动（斯塔克伯格主从博弈）
建模步骤
  1. 识别参与人、各自策略集与收益（效用），统一收益量纲
  2. 构建收益矩阵（同时行动）或扩展式（有先后顺序）
  3. 纯策略用划线法/反应函数求纳什均衡；无纯策略则解混合策略概率
  4. 零和情形转化为线性规划求 maxmin 值；大规模用迭代或蒙特卡洛仿真
  5. 分析均衡效率、对收益参数的敏感性并给现实解释
要点与易错
  • 博弈论是"多个决策者"，多目标规划是"一个决策者的多个目标"，二者不要混淆
  • 必须显式刻画对手的反应，单方最优化不是博弈；收益矩阵要对称完整
  • 小矩阵可枚举，策略空间大时用反应动力学迭代或基于智能体的仿真

真题中的规划模型

实例 1 · 海底数据中心（约束建模）问题一同时建空间尺寸约束（三种排列，纯空间最多 465 台）与散热约束（稳态产热=散热，热对流方程最多 119 台），取较小值；问题二加翅片后以服务器数量最大为目标建整数规划，Lingo 得 401 台、168 翅片；问题三加下潜深度约束得 423 台。示范"多约束取交集、逐问加约束"。

03启发式优化算法

问题 NP-hard、不可导、规模大、局部极值极多时，精确求解器失效，启发式在合理时间内求高质量近似解，是优化题的"最后一公里"武器。点开卡片看机理公式、适用场景、参数与步骤。
出现频率：高难度 ★★★TSP/排班/大规模规划
使用前提（写进论文的选择依据）：先说明问题为何无法精确求解（组合爆炸/非凸/黑箱目标），再引出启发式；并交代种群规模、迭代次数、初值或随机种子、终止条件与多次运行的稳定性，这正是优秀论文"算法与求解"维度最常缺失的内容。
模拟退火 SA邻域搜索高频▾模拟金属降温：高温时以一定概率接受劣解跳出局部最优，低温趋于贪心，参数少、鲁棒。
核心公式
劣解接受概率 P=exp(−ΔE/T)（ΔE 为目标增量，最小化时为正）；降温 T←αT，α=0.95~0.99
应用场景
  • 单目标连续/组合优化、TSP、排班、车间调度
  • 目标函数非凸、多局部极值，梯度法容易陷住时
建模步骤
  1. 初始解 x₀、初始温度 T₀（高到初始劣解接受率约 0.8）
  2. 邻域扰动产生新解，算目标差 ΔE
  3. 更优则接受；更劣以概率 exp(−ΔE/T) 接受
  4. 同温层内循环 L 次后按 T←αT 降温
  5. 到终止温度或迭代上限停止，输出历史最优（scikit-opt 的 sko.SA）
要点与易错
  • 降温太快会早熟、太慢效率低；固定随机种子并多次运行，结果只能称"近似最优"。
遗传算法 GA种群进化高频▾把解编码成染色体，用选择、交叉、变异三代算子优胜劣汰，并行搜索多区域，国赛最常用。
核心公式
适应度 F(x)（由目标变换，越大越好）；轮盘赌选择概率 pᵢ=Fᵢ/ΣF；交叉概率 pc≈0.7-0.9、变异概率 pm≈0.01-0.1
应用场景
  • 混合整数规划、TSP/VRP 路径、排班、车间调度、函数全局优化
  • 多目标用 NSGA-II 求 Pareto 前沿
建模步骤
  1. 编码：二进制/实数/排列（TSP 用排列编码，与决策变量结构一致）
  2. 初始化种群（50 起步），定义适应度（含约束罚函数）
  3. 选择（锦标赛 k=3 更稳）→ 交叉（排列用 OX）→ 变异
  4. 迭代 200 代左右，保留精英，画收敛曲线判断稳定
要点与易错
  • 论文必给收敛曲线图（迭代代数 vs 最优目标）并多次运行报均值方差
  • 2021C 用 GA 求大规模订购运输方案；2024C 国奖论文以"差分遗传算法"为标题亮点
粒子群优化 PSO群体协作中频▾每个粒子参考自身历史最优和群体最优更新速度位置，连续空间收敛快、参数少。
核心公式
v←w·v+c₁r₁(pbest−x)+c₂r₂(gbest−x)；x←x+v；惯性权重 w 常从 0.9 线性递减到 0.4
应用场景
  • 连续函数优化、参数寻优、神经网络权值初始化
  • 需要快速得到高质量解、维度中等的问题
建模步骤
  1. 初始化粒子位置与速度、pbest、gbest
  2. 逐代按公式更新速度位置并越界处理
  3. 更新个体/群体最优，w 线性递减平衡探索与开发
  4. 到代数停止输出 gbest（sko.PSO 开箱即用）
要点与易错
  • 速度要设上限防飞出；离散问题需离散化 PSO，此时 GA 通常更顺手。
蚁群 ACO 与禁忌搜索（了解）信息素低频▾蚁群靠信息素正反馈适配路径问题，禁忌搜索用禁忌表避免回头，了解思想、会调包即可。
核心公式
ACO 转移概率 p∝τᵅ·ηᵝ（信息素 τ、启发度 η=1/距离）；信息素更新 τ←(1−ρ)τ+Δτ；禁忌搜索靠禁忌表+特赦准则
应用场景
  • ACO：TSP、VRP 等路径构造类问题
  • 禁忌搜索：组合优化、 job-shop，允许"上山步"跳出局部最优
建模步骤
  1. ACO：初始化信息素，蚂蚁按概率选边，走完一圈更新信息素（挥发+沉积）
  2. 迭代至收敛，记录最短路径
  3. 禁忌搜索：邻域移动 + 禁忌表封锁近期移动 + 特赦最优移动
要点与易错
  • ACO 参数多、收敛慢，小规模问题 GA/SA 更划算；蜂群鱼群狼群等了解思想即可，不必贪多。
共性易错：① 不固定随机种子导致不可复现；② 只跑一次就下结论；③ 无收敛曲线、不与贪心/随机基线对比；④ 把迭代解直接称"最优解"，应称"近似最优"；⑤ 启发式不保证满足约束，罚函数设计后必须核验可行性。

MODULE 04 · GRAPH

04图论与路径规划

把对象抽象为点、关系抽象为带权边，解决最短路、连通、生成树、网络流、匹配与调度问题。NetworkX 几行代码即可求解，难点在"如何把题意建图"。点开卡片看算法公式、场景与步骤。
出现频率：中高难度 ★★★路径/物流/管网/任务分配
Dijkstra 单源最短路非负权高频▾从一个源点贪心扩展最近节点，求到所有点的最短距离，要求边权非负。
核心公式
松弛操作：d[v]=min(d[v], d[u]+w(u,v))；每次取未确定节点中 d 最小者定型，堆优化复杂度 O((n+m)log n)
应用场景
  • 路网导航、物流配送最短距离/时间、管道铺设选线
  • 边权为距离、成本、时间等非负值的单起点问题
建模步骤
  1. 建邻接表（无向边加两次、有向边加一次）
  2. 源点距离 0，其余 ∞，最小堆反复取最近点松弛邻居
  3. 记录前驱节点回溯具体路径
  4. nx.single_source_dijkstra 验证手算结果
要点与易错
  • 存在负权边时 Dijkstra 会出错（不报错但结果错），此时换 Bellman-Ford。
Bellman-Ford / SPFA（含负权）允许负权中频▾对所有边反复松弛，允许负权边并能检测负环，SPFA 是其队列优化版。
核心公式
每轮对全部边做 d[v]=min(d[v],d[u]+w)，最多 n−1 轮收敛；第 n 轮还能松弛说明存在负环
应用场景
  • 边权可能为负（收益、套利、折算成本）的最短路
  • 需要判断系统是否存在"越转越优"的负环（金融套利、循环增益）
建模步骤
  1. 建边表 (u,v,w)
  2. 初始化距离，循环松弛 n−1 轮
  3. 多做一轮判断负环；实际用 SPFA 队列只处理被更新点提速
要点与易错
  • 复杂度 O(nm) 高于 Dijkstra，确认无负权优先用 Dijkstra。
Floyd-Warshall 全源最短路全源/可手算高频▾三重循环一次性算出任意两点间最短距离，稠密图、小 n 时最好用，本质是三维动态规划。
核心公式
dᵢⱼᵏ=min(dᵢⱼᵏ⁻¹, dᵢₖᵏ⁻¹+dₖⱼᵏ⁻¹)，循环顺序必须是 k→i→j；初始化 dᵢᵢ=0、无边为 ∞
应用场景
  • 需要任意两点间距离矩阵（选址评价、可达性分析）
  • 节点数不多（<200）、可在论文中展示矩阵迭代过程
建模步骤
  1. 初始化距离矩阵 D⁰（对角线 0、直接边为权、其余 ∞）
  2. 以每个 k 为中转更新 i 到 j 的更短路径
  3. 同步记录路径矩阵还原走法，nx.floyd_warshall 验证
要点与易错
  • 循环顺序写反结果全错；O(n³)，大稀疏图改用 n 次 Dijkstra。
最小生成树（Kruskal / Prim）连通布线中频▾用最小总权边把所有点连通且不成环，用于管网、路网、通信布线的最低成本设计。
核心公式
Kruskal：边按权升序，不构成环（并查集判环）就加入，直到 n−1 条边；Prim：从一点出发每次连最近的新点
应用场景
  • 村村通公路/管网/通信基站布线，总造价最小
  • 聚类的单链准则、网络骨架提取
建模步骤
  1. 点为设施、边权为造价/距离
  2. 稀疏图用 Kruskal+并查集，稠密图用 Prim
  3. 输出选中边与总权值，画最小生成树图
要点与易错
  • 生成树保证"连通且无环、恰 n−1 条边"；要求每个点度数受限要加约束转整数规划。
最大流 / 最小割运力瓶颈中频▾求源点到汇点的最大输送能力，最大流数值恒等于最小割容量，用于运力与瓶颈分析。
核心公式
残量网络找增广路增流，直到不存在增广路（Ford-Fulkerson 思想，Dinic 用分层图加速）；最大流=最小割
应用场景
  • 交通/管网/电网的最大通行能力、瓶颈路段识别
  • 任务分流、供需匹配、图像分割（s-t 割）
建模步骤
  1. 多源多汇时加超级源 S、超级汇 T
  2. 边容量=运力上限，反向边初始 0
  3. Dinic/EK 求最大流，最小割边集即瓶颈
要点与易错
  • 无向容量边要加两条方向边；节点自身有容量时拆点为边。
二分图匹配（匈牙利算法）任务指派中频▾两侧节点一一配对（人-任务、工人-工位），求最多/最优匹配，带权最优指派用匈牙利法。
核心公式
增广路：为左侧点找右侧空位，被占则尝试让原匹配方改配，反复腾挪；带权指派 min Σcᵢⱼxᵢⱼ，Σⱼxᵢⱼ=1
应用场景
  • 人员-任务指派、工人-工位、学生-导师双向选择
  • 匹配数最大化或总代价最小化
建模步骤
  1. 判断能否构成二分图（两侧内部无边）
  2. 最大匹配用匈牙利增广路；最优指派用 linear_sum_assignment
  3. 输出配对表与总代价
要点与易错
  • 一对多要把一侧"复制"成多个虚拟节点；人数任务数不等补虚拟节点。

建图通用要点

  • 有向/无向、是否带权：关系单向（工序先后）用 DiGraph；距离/成本/时间作边权
  • 虚拟源汇：多起点多终点加超级源 S、超级汇 T 转单源问题
  • 最短路与 DP 互通：Floyd 的 dᵢⱼᵏ 本质是三维 DP
  • TSP ≠ 最短路：TSP 要经过所有点恰好一次并回到起点，属 NP-hard，用第 3 章启发式
论文里怎么用路径题先给网络拓扑图（节点-边可视化是加分图），再给算法流程图与距离/路径结果表；验证要做可执行回放：把求出的路径代回原图逐段累加边长，核对总距离与算法输出一致，并测试不同起点。

05回归分析

用自变量解释/预测连续因变量，是预测题的第一块基石。重点不只是拟合，更是"诊断"：模型是否显著、变量是否该留、共线性与残差是否过关。点开卡片看公式、场景、步骤与判据。
出现频率：极高难度 ★★156 篇论文中出现 64 篇次
一元 / 多元线性回归 OLS最小二乘高频▾假设因变量是自变量的线性组合加噪声，最小化残差平方和求系数，statsmodels 一行出全部检验。
核心公式
y=β₀+β₁x₁+…+βₖxₖ+ε，ε~N(0,σ²)；最小化 Σ(y−ŷ)² 得 β=(XᵀX)⁻¹Xᵀy
应用场景
  • 因素贡献分析：哪些自变量显著影响结果、影响方向与大小
  • 基线预测：产量、销量、能耗等连续值，且关系近似线性
建模步骤
  1. 画散点矩阵/相关热力图判断线性趋势与异常点
  2. OLS(y, add_constant(X)).fit().summary() 输出报表
  3. 看 F 检验（方程整体 p<0.05）、t 检验（单变量 p 值）、R²/调整 R²
  4. 残差诊断：零均值、同方差、正态、无自相关（DW 检验、Q-Q 图）
要点与易错
  • R² 随变量数只增不减，变量多时看调整 R²；F 不显著说明整个模型不成立
  • 系数解释要带"其他变量不变时，x 每增加 1 单位 y 平均变化 β"的现实含义
回归诊断：共线性、异方差、异常点可靠性高频▾OLS 成立有前提，用 VIF、残差图、库克距离逐项体检，是论文严谨性的直接体现。
核心公式
方差膨胀因子 VIFⱼ=1/(1−R²ⱼ)，VIF>10 共线性严重；加权最小二乘 WLS 权重 ∝1/σ²；库克距离 Dᵢ 衡量第 i 点对系数的影响
应用场景
  • 自变量彼此相关（经济指标、理化成分）导致系数不稳、符号反常
  • 残差呈漏斗形（异方差）、个别样本主导回归结果
建模步骤
  1. 算每个自变量 VIF，超 10 则剔除/合并/正则化
  2. 残差-拟合图判异方差，必要时对数变换或 WLS
  3. Cook's D 找强影响点，核实数据后单独讨论，不静默删除
要点与易错
  • 共线性不影响预测但毁掉系数解释，做因素分析时必须处理。
岭回归 / Lasso / 逐步回归正则化与选变量中频▾共线性或变量过多时，用惩罚项压缩系数：岭回归缩而不归零，Lasso 能直接选变量，逐步回归按显著性增减。
核心公式
岭（L2）：min Σ(y−ŷ)²+λΣβ²；Lasso（L1）：min Σ(y−ŷ)²+λΣ|β|（稀疏、可置零选变量）；逐步：按 AIC/BIC 或 p 值双向增减
应用场景
  • 自变量多且相关、样本量不大，OLS 系数爆炸
  • 需要筛出少数关键驱动因素（Lasso 变量选择）
建模步骤
  1. 标准化自变量（惩罚对尺度敏感）
  2. 交叉验证选 λ（岭迹图/Lasso 路径）
  3. 逐步回归则从空/满模型出发按 AIC 双向筛，报告最终变量
要点与易错
  • λ 必须交叉验证选取并画岭迹/系数路径图；不标准化会被量纲大的变量主导。
非线性回归（变量变换 / curve_fit）曲线关系高频▾散点呈指数、幂、S 形等曲线：能线性化先变换再 OLS，不能线性化用非线性最小二乘直接拟合。
核心公式
指数 y=aeᵇˣ 取 ln y 线性化；幂 y=axᵇ 双对数线性化；一般形式 min Σ(y−f(x;θ))²，scipy curve_fit 迭代求 θ 与置信区间
应用场景
  • 增长饱和过程：Logistic 人口/技术扩散、Michaelis-Menten 酶动力学
  • 多项式趋势（加 x²、x³ 项）、已知机理形式的参数标定
建模步骤
  1. 散点判断曲线族，能线性化优先变换（注意误差结构随之改变）
  2. 否则写机理函数给 curve_fit 合理初值，多初值防陷局部解
  3. 报参数置信区间、拟合曲线与残差，外推要谨慎
要点与易错
  • 多项式阶数过高会过拟合、边界剧烈震荡，一般不超过 3 阶并比较调整 R²。
Logistic 回归（跨入分类）概率分类高频▾因变量是 0/1 时对发生概率的 logit 建模，系数可解释为几率比，是分类与因素分析两用的利器。
核心公式
ln(p/(1−p))=Xβ，即 p=1/(1+e^(−Xβ))；系数取指数 exp(β) 为几率比 OR；多分类用 softmax 多项逻辑回归，最大似然估计
应用场景
  • 二分类/多分类且需要解释每个因素的作用方向与大小
  • 风险预警、是否违约/患病/流失、类别判别（2022C 玻璃类型）
建模步骤
  1. 标准化自变量，最大似然拟合
  2. Wald/p 值看显著性，exp(β) 解释几率变化
  3. 按 0.5（或业务阈值）分类，画 ROC、报 AUC
要点与易错
  • 2022C 的漂亮用法：正向学"类型-成分"规律做分类，逆向固定类型遍历成分反推风化前含量，同一模型两用
  • 样本不平衡要调阈值或 class_weight，详见 第 7 章
SVR 与树回归（进阶非线性）机器学习回归中频▾关系高度非线性、交互复杂时用 SVR、随机森林回归、XGBoost，精度高但要用对比和特征重要性补解释性。
核心公式
SVR：min ½‖w‖² s.t. |y−ŷ|≤ε（ε-不敏感带，RBF 核 K=exp(−γ‖x−x′‖²)）；树回归：最小化叶子节点不纯度（方差）递归分裂
应用场景
  • 变量交互强、无线性形式、数据量中等以上
  • 作为线性回归的对比模型，体现模型选择过程
建模步骤
  1. SVR 调 C、gamma、epsilon；树调深度/棵数，全部交叉验证
  2. 与线性回归同口径比较留出期 RMSE/MAPE
  3. 用特征重要性或 SHAP 解释"黑箱"
要点与易错
  • 只报复杂模型不报基线=没有选择依据；小样本上复杂模型未必赢线性模型。
预测类题验证组合（证据链）时间回测/留出集 + 简单基线（均值法、线性回归）对比 + MAE/RMSE/MAPE 分层误差 + 残差图；只报一个 R² 而不做基线对比属于验证不足。误差公式见 公式速查。

MODULE 06 · TIME SERIES

06时间序列预测

数据按时间排列、要外推未来。先看数据量与机理：4-10 个点的小样本单调序列用灰色；长序列用 ARIMA 家族；复杂非线性用 LSTM。选错方法比算错更致命。点开卡片看公式、场景与定阶步骤。
出现频率：高难度 ★★★预测/外推/预警
灰色预测 GM(1,1)小样本单调高频▾对序列一次累加消波动，建一阶白化微分方程，4 个数据点就能做短期预测，国赛小样本神器。
核心公式
累加 x¹=cumsum(x⁰)，白化方程 dx¹/dt+ax¹=b；最小二乘 [a,b]ᵀ=(BᵀB)⁻¹BᵀY
时间响应式 x̂¹(k+1)=(x⁰(1)−b/a)e^(−ak)+b/a，再累减还原 x̂⁰(k+1)=x̂¹(k+1)−x̂¹(k)
应用场景
  • 只有 4-10 个年度/期数据、趋势近似单调（人口、能耗、指标增长）
  • 缺机理、缺外生变量，需要快速给出短期外推与区间
建模步骤
  1. 级比检验 λ(k)=x(k−1)/x(k) 落在 (e^(−2/(n+1)),e^(2/(n+1))) 才适用，否则平移变换
  2. 累加、紧邻均值序列 z¹=0.5(x¹(k)+x¹(k−1))，构造 B、Y 求 a、b
  3. 响应式外推后累减还原
  4. 后验差检验：C=S₂/S₁<0.35 优、<0.5 合格，小误差概率 P>0.95
要点与易错
  • 只适合单调、短期（3-5 期）：−a<0.3 可中长期，0.3-0.5 仅短期，>0.8 禁用；波动/季节序列禁用
  • 新信息优先可用新陈代谢 GM：加入最新值、去掉最旧值滚动预测
AR / MA / ARMA 平稳族平稳序列中频▾平稳序列用自身历史值（AR）和历史随机冲击（MA）解释现在，是 ARIMA 的基础组件。
核心公式
AR(p)：xₜ=c+Σφᵢxₜ₋ᵢ+εₜ；MA(q)：xₜ=μ+Σθⱼεₜ₋ⱼ+εₜ；ARMA(p,q)：两者叠加
应用场景
  • 均值、方差不随时间漂移的平稳序列（检验后）
  • 短期惯性预测、缺外生变量的统计外推
建模步骤
  1. 时序图 + ADF 检验确认平稳
  2. 看 ACF/PACF 截尾拖尾初步定 p、q
  3. AIC/BIC 网格精定阶，拟合后 LB 检验残差为白噪声
要点与易错
  • 非平稳直接套 ARMA 会产生伪回归，必须先差分，即进入 ARIMA。
ARIMA(p,d,q)（最常用）非平稳高频▾先差分把非平稳序列变平稳，再建 ARMA，"差分阶数+自回归+移动平均"三参数覆盖大多数时序。
核心公式
d 阶差分 ∇xₜ=xₜ−xₜ₋₁ 使序列平稳，再对 ∇x 建 ARMA(p,q)；季节版 SARIMA=(p,d,q)(P,D,Q,s)，s 为周期
应用场景
  • 几十个以上观测、含趋势的非平稳序列（销量、客流、指标）
  • 有年/季/月周期用 SARIMA；带外生变量（天气、价格）用 ARIMAX
建模步骤
  1. ADF 检验，p<0.05 为平稳，否则差分至平稳确定 d
  2. ACF/PACF 初定 p、q，pmdarima.auto_arima 按 AIC 自动定阶
  3. 拟合并诊断：残差零均值、LB 白噪声、近似正态
  4. 留出最后若干期做样本外回测，报 RMSE/MAPE，再全量重拟合外推
要点与易错
  • 定阶口诀：AR 看 PACF 截尾、MA 看 ACF 截尾，都拖尾即 ARMA
  • 差分阶数一般不超过 2，过度差分会丢信息；预测区间要随步长放大
指数平滑 / Prophet（补充）趋势季节中频▾指数平滑用递推加权平均，Prophet 把趋势、季节、节假日相加建模，适合有明显周期、要快速落地的业务序列。
核心公式
一次指数平滑 Sₜ=αxₜ+(1−α)Sₜ₋₁；Holt 线性、Holt-Winters 再加季节项；Prophet：y(t)=g(t)趋势+s(t)季节+h(t)节假日+ε
应用场景
  • 数据有稳定趋势与季节、缺失/异常较多、要求稳健快出结果
  • 作为 ARIMA 的对比基线
建模步骤
  1. 无趋势用简单指数平滑，有趋势用 Holt，趋势+季节用 Holt-Winters
  2. 平滑系数 α/β/γ 可网格搜索，Prophet 直接拟合并给不确定区间
  3. 同样做留出期回测对比
要点与易错
  • 指数平滑对突变响应慢；Prophet 需要足够长的周期重复（至少 2-3 个周期）。
LSTM 时序预测与多模型选型长依赖大数据中频▾数据量大、非线性强、依赖久远时用 LSTM；但小样本上它常输给灰色/ARIMA，务必对比后再选。
核心公式
用滑动窗口把前 w 期 [xₜ₋w…xₜ₋₁] 构造成特征预测 xₜ；LSTM 靠输入门/遗忘门/输出门与细胞状态传递长程信息（详见第 9 章）
应用场景与选型
  • 4-10 点、单调小样本 → GM(1,1)
  • 几十点、差分后平稳 → ARIMA/SARIMA；有外生变量 → ARIMAX/Prophet
  • 大量数据、强非线性、长依赖 → LSTM/GRU；有明确物理机理 → 微分方程（第 11 章）
建模步骤
  1. 归一化、滑动窗口造样本，按时间先后划分（不能随机打乱）
  2. 训练 LSTM，早停防过拟合
  3. 反归一化，与灰色/ARIMA 同口径比留出期误差，择优后全量重训
要点与易错
  • 高分做法是多模型对比用留出期 RMSE/MAPE 选模型；时序数据随机划分训练测试=严重泄漏。

MODULE 07 · CLASSIFICATION

07有监督分类与判别

有已知类别标签，学一条分类边界去判别新样本。国赛数据题高频：玻璃/葡萄酒/水质类别、故障诊断、风险识别。核心是"训练-测试隔离 + 多指标评估 + 可解释"。点开卡片看判别公式、场景与步骤。
出现频率：高难度 ★★★常与聚类/统计检验组合
Fisher 线性判别 LDA线性可解释高频▾找一个投影方向让类间尽量分开、类内尽量聚拢，小样本可解释分类的首选。
核心公式
最优投影 w∝S_w⁻¹(μ₁−μ₂)，类内散度 S_w=Σ(x−μₖ)(x−μₖ)ᵀ，类间散度 S_b=(μ₁−μ₂)(μ₁−μ₂)ᵀ，最大化 J=wᵀS_bw/wᵀS_ww
应用场景
  • 类别近似线性可分、样本不多、需要写出判别函数和依据
  • 多类降维可视化（LDA 也是有监督降维）
建模步骤
  1. 算各类均值与类内散度矩阵
  2. 求 S_w⁻¹S_b 特征向量得判别方向，投影后按阈值/马氏距离分类
  3. 交叉验证报准确率，画投影分布图
要点与易错
  • 假设各类近似同协方差；S_w 奇异（特征多于样本）时先 PCA 降维。
Logistic 逻辑回归概率分类高频▾输出属于各类的概率，系数 exp(β) 可解释为几率比，分类与因素分析两用。
核心公式
p=1/(1+e^(−Xβ))，最大似然估计 β；多分类 softmax：pₖ=e^(Xβₖ)/Σe^(Xβⱼ)；exp(β)=几率比 OR
应用场景
  • 二分类/多分类且要解释各因素作用（风险、故障、类别判别）
  • 需要概率输出做阈值决策
建模步骤
  1. 标准化特征，拟合逻辑回归（正则化强度交叉验证）
  2. 看系数显著性与 OR，画 ROC 选阈值、报 AUC
  3. 混淆矩阵 + F1 评估
要点与易错
  • 2022C 三层用法：学分类规律、预测未知样本、逆用表达式反推风化前成分，是模型复用的经典。
K 近邻 KNN简单基线中频▾不训练模型，新样本看最近的 K 个邻居多数属于谁，最简单的非参数分类基线。
核心公式
距离 d(x,xᵢ)=√Σ(xⱼ−xᵢⱼ)²（欧氏，须先标准化）；多数投票 y=argmax 邻居类别计数；K 取奇数，交叉验证选
应用场景
  • 类别边界不规则、样本量小，作为快速基线
  • 推荐、异常邻近查找
建模步骤
  1. 标准化/归一化（否则量纲决定距离）
  2. 交叉验证选 K 与距离度量
  3. 概率可按邻居比例输出
要点与易错
  • 维度高时距离失效（维数灾难），先降维；样本大时预测慢。
朴素贝叶斯概率基线低频▾用贝叶斯公式 + 特征条件独立假设，直接算各类后验概率，小样本、文本分类高效。
核心公式
后验 P(y|x)∝P(y)ΠP(xⱼ|y)（条件独立假设）；连续特征用高斯 NB（P(xⱼ|y)~N(μ,σ²)），离散用多项式/伯努利 NB
应用场景
  • 文本/垃圾邮件分类、小样本概率判别
  • 作为概率基线与复杂模型对比
建模步骤
  1. 估计先验 P(y) 与各特征条件分布
  2. 对新样本算各类后验取最大
  3. 连续变量先分箱或用高斯假设
要点与易错
  • 条件独立假设较强，特征强相关时准确率受限，但通常仍稳健快速。
支持向量机 SVM小样本高维中频▾最大化类别间隔构造分界面，核技巧处理非线性，小样本、高维下表现稳定。
核心公式
max 2/‖w‖ 间隔，软间隔 min ½‖w‖²+CΣξ；核函数 RBF：K(x,x′)=exp(−γ‖x−x′‖²)，C 控容忍、γ 控边界复杂度
应用场景
  • 样本不多、维度高（理化指标、光谱数据）、非线性边界
  • SVC 分类、SVR 回归、One-Class SVM 异常检测
建模步骤
  1. 必须标准化，选线性/RBF 核
  2. GridSearchCV 网格调 C、gamma
  3. 二维特征画决策边界可视化是好图
要点与易错
  • gamma 过大、C 过大会过拟合；大样本训练慢，可换线性 SVM 或集成树。
决策树可解释规则中频▾按特征阈值递归二分，产出 if-then 规则树，可解释性最强，也是随机森林的基模型。
核心公式
分裂选信息增益最大：熵 H=−Σpₖlog pₖ，增益=H(父)−Σ(nₖ/n)H(子)；CART 用 Gini=1−Σpₖ²；剪枝防过拟合
应用场景
  • 需要白纸黑字的判别规则（评级、诊断标准）
  • 混合量纲、缺失值容忍度高的分类/回归
建模步骤
  1. 按 Gini/熵递归选最优分裂特征与阈值
  2. 限制 max_depth、min_samples_leaf 并剪枝
  3. 画树图、输出特征重要性
要点与易错
  • 单棵树不控深度极易过拟合、方差大，竞赛中通常用集成树替代。
随机森林 / XGBoost 集成学习高精度集成高频▾多棵树投票/梯度提升，精度高、抗过拟合、给特征重要性，表格数据竞赛的主力。
核心公式
随机森林=Bagging：样本有放回抽样 + 每分裂随机选特征，多树投票降方差；XGBoost=Boosting：沿负梯度逐棵加树拟合残差，目标含正则项
应用场景
  • 特征多、非线性、交互复杂的表格分类/回归，追求精度
  • 需要特征重要性做因素分析
建模步骤
  1. 调树数、深度、学习率（XGB），早停
  2. K 折交叉验证，混淆矩阵/F1/AUC 评估
  3. 输出特征重要性或 SHAP 补解释
要点与易错
  • 类别不平衡用 class_weight/SMOTE/调阈值；黑箱模型必须配可解释分析与简单基线对比。
评估闭环（务必写全）：分层抽样 train_test_split（stratify=y）→ 混淆矩阵 + 准确率/精确率/召回率/F1（不平衡看 F1 与召回）→ K 折交叉验证 → 与至少一个简单基线对比。标准化只能在训练集上 fit，再 transform 测试集，否则数据泄漏。
易错：全数据标准化后再划分（泄漏）；只报准确率掩盖类别不平衡；不交叉验证、结果靠一次随机划分；树模型不控深度导致过拟合。

MODULE 08 · CLUSTERING

08无监督聚类与降维

没有标签时，按相似性把样本分群（亚类划分、客户分群、异常发现），或用降维把高维指标压缩成少数综合因子。聚类没有标准答案，必须靠轮廓系数等指标证明"分得合理"。点开卡片看判据公式、场景与步骤。
出现频率：高难度 ★★★亚类/分群/综合评价
K-means 聚类划分法高频▾指定簇数 K，迭代"分配到最近质心-更新质心"把样本分成球形簇，最常用的聚类基线。
核心公式
目标 min ΣₖΣᵢ∈Cₖ‖xᵢ−μₖ‖²；质心 μₖ=(1/|Cₖ|)Σx；轮廓系数 s=(b−a)/max(a,b)∈[−1,1]，越近 1 越好
应用场景
  • 客户/样本分群、亚类划分（2022C 问题二）、图像压缩、异常初筛
  • 簇近似球形、规模相近、簇数可估计
建模步骤
  1. 特征标准化（距离对量纲极敏感，必须做）
  2. 肘部法（SSE 拐点）+ 轮廓系数双重定 K，多次初始化取最优
  3. 迭代至质心稳定，固定 random_state 可复现
  4. PCA/t-SNE 降维到二维散点着色展示
要点与易错
  • 2022C 完整证据链：聚类 + 合理性（轮廓系数、类间差异）+ 敏感性（改 K、扰动数据看是否稳定）
  • 对初值和异常点敏感，用 K-means++ 初始化；非球形簇应换 DBSCAN
层次聚类树状结构中频▾按距离逐级合并（凝聚）或分裂，输出树状图，不必预先指定簇数，小样本看层级关系。
核心公式
类间距离四种连接：single 最近、complete 最远、average 平均、ward 最小化合并后方差增量（最常用）
应用场景
  • 样本量不大（几百以内）、想看"大类套小类"的层级
  • 需要树状图 dendrogram 辅助决定切几类
建模步骤
  1. 标准化，算距离矩阵
  2. ward 连接凝聚聚类，画树状图
  3. 按高度或期望簇数横切得到类别
要点与易错
  • 复杂度 O(n²) 以上，大样本慢；链式形状是 single 连接的典型毛病，优先 ward/average。
DBSCAN 密度聚类任意形状+异常中频▾按密度连通性成簇，不需要预设簇数，能发现任意形状簇并自动标出噪声离群点。
核心公式
参数 eps（邻域半径）、min_samples（成核最少点数）；核心点邻域内点数≥min_samples，密度可达点连成簇，其余为噪声
应用场景
  • 簇形状不规则、大小不一、含明显噪声（地理点位、异常检测）
  • 不想预设 K、希望算法自动给噪声标签
建模步骤
  1. 标准化，用 k-距离图（第 k 近邻距离排序拐点）选 eps
  2. 调 min_samples，拟合后看簇数与噪声比例是否合理
  3. 与 K-means 结果对比讨论
要点与易错
  • 密度不均时效果差，可换 HDBSCAN；高维数据先降维，否则距离失去区分度。
高斯混合模型 GMM（软聚类）概率归属中频▾假设数据由若干高斯分布混合生成，EM 迭代估计参数，输出每个样本属于各簇的概率。
核心公式
p(x)=ΣₖπₖN(x|μₖ,Σₖ)；EM：E 步算归属责任度 γ，M 步更新 π、μ、Σ；BIC/AIC 选成分数 K
应用场景
  • 簇呈椭球、需要软归属概率而非硬划分
  • 聚类同时做密度估计与异常打分（低似然即异常）
建模步骤
  1. 标准化，按 BIC 曲线选 K
  2. EM 拟合（K-means 初始化更稳）
  3. 输出概率矩阵与椭球置信区间可视化
要点与易错
  • 协方差矩阵类型（full/tied/diag/spherical）要按簇形状选；样本少时协方差易奇异。
主成分分析 PCA线性降维高频▾把多个相关指标正交变换为少数互不相关的主成分，用于去相关、降维、可视化和综合评价。
核心公式
协方差矩阵特征值分解，主成分方向=特征向量 w，方差贡献=λ/Σλ；累计方差贡献率 ≥85% 保留；综合得分 F=Σ(λₖ/Σλ)Fₖ
应用场景
  • 指标高度相关、想压缩成几个综合指标做评价
  • 高维可视化（降到 2-3 维）、为后续模型去共线、降噪
建模步骤
  1. 标准化（PCA 对尺度敏感），KMO>0.6、Bartlett p<0.05 才适合
  2. 看碎石图与累计贡献率定主成分个数
  3. 看载荷矩阵解释主成分含义，算综合得分排名
要点与易错
  • 主成分是数学正交方向，不一定有现实含义，需要可命名的"潜因子"时用因子分析。
因子分析 FA潜变量中频▾假设观测指标由少数潜在公共因子驱动，旋转后因子可现实命名，比相关矩阵更凝练。
核心公式
X=AF+ε（载荷矩阵 A、公共因子 F、特殊因子 ε）；方差最大正交旋转使载荷两极化便于命名；KMO>0.6、Bartlett p<0.05
应用场景
  • 问卷/指标背后有可解释的潜在维度（能力、水平、因子结构）
  • 2022C 问题四把玻璃成分归纳为少数因子再比较两类差异
建模步骤
  1. 适用性检验（KMO/Bartlett）
  2. 按特征值>1 或累计方差定因子数
  3. 方差最大旋转，按高载荷指标命名因子，算因子得分
要点与易错
  • 旋转后仍无清晰高载荷结构说明潜变量假设不成立，退回 PCA 或相关分析。
聚类/降维都属于无监督，没有标准答案就更要给指标：轮廓系数、CH 指数、累计方差贡献率、KMO，并用可视化佐证，避免"我觉得分成三类"。

MODULE 09 · NEURAL NETWORK

09神经网络与深度学习

数据量大、关系高度非线性时的"重武器"，比赛中以 BP 和 LSTM 最常用。务必先试简单模型：神经网络是精度上限的冲刺而不是第一选择，且必须防过拟合、能验证。点开卡片看结构公式、场景与训练步骤。
出现频率：中难度 ★★★★大数据/图像/复杂预测
BP 神经网络（多层感知机 MLP）前馈万能逼近高频▾信号前向计算、误差反向传播调权，能拟合任意非线性映射，是非线性回归/分类的通用器。
核心公式
前向 a=φ(Wx+b)；反向按梯度下降更新 W←W−η·∂L/∂W；隐层激活 ReLU=max(0,z)，分类输出 softmax、回归输出线性
应用场景
  • 非线性函数拟合、预测、分类，且线性/树模型残差较大
  • 多输入-多输出的复杂映射（性能预测、参数-质量关系）
建模步骤
  1. 数据归一化到 [0,1] 或标准化，按比例划分训练/验证/测试
  2. 单隐层起步，隐节点数按 √(输入+输出)+a（1-10）试，交叉验证选
  3. 选激活与损失（回归 MSE、分类交叉熵），画训练/验证损失曲线
  4. 测试集评估并与线性/树模型对比，报告双误差
要点与易错
  • 防过拟合四件套：早停、Dropout、L2 权重衰减、验证集调结构，必须写进论文
  • sklearn MLPRegressor/Classifier 最简单，复杂结构用 PyTorch；样本少于几百时优先统计模型
CNN 卷积神经网络图像/空间低频▾用卷积核局部扫描 + 池化提取空间特征，题目给图像（影像、遥感、字符）时才需要。
核心公式
卷积 Y(i,j)=ΣΣ W·X(i:i+k,j:j+k)+b；特征图尺寸 =(n−k+2p)/s+1；池化取局部最大/平均降采样
应用场景
  • 医学影像分类/分割、遥感地物识别、字符/缺陷检测
  • 网格型数据（也可把时序、相关矩阵当"图"输入）
建模步骤
  1. "卷积-激活-池化"堆叠提特征，末端全连接输出
  2. 小数据用预训练模型迁移学习 + 数据增强
  3. 同样划分验证集早停，给混淆矩阵与热力图
要点与易错
  • 国赛图像题年份很少，针对性准备即可；数据量小硬训 CNN 必过拟合，优先迁移学习。
RNN 循环神经网络序列基础低频▾隐状态在时间步间传递，建模"当前依赖历史"，但长序列会梯度消失，已多被 LSTM/GRU 取代。
核心公式
hₜ=φ(Wₓxₜ+Wₕhₜ₋₁+b)，输出 yₜ=Wᵧhₜ；参数随时间共享，BPTT 反向传播
应用场景
  • 短序列建模、理解循环结构（LSTM 的前置知识）
建模步骤
  1. 构造等长序列样本，按时间划分
  2. 观察梯度是否消失，序列一长直接换 LSTM/GRU
要点与易错
  • 梯度消失/爆炸是 RNN 的结构性问题，长依赖任务不要硬用。
LSTM / GRU 时序网络长依赖中频▾用门控和细胞状态让信息长期传递，适合大数据量长序列预测，GRU 参数更少、小数据更稳。
核心公式
遗忘门 fₜ=σ(Wf·[hₜ₋₁,xₜ])、输入门 iₜ、输出门 oₜ；细胞 Cₜ=fₜCₜ₋₁+iₜC̃ₜ，hₜ=oₜtanh(Cₜ)；GRU 合并为更新门/重置门
应用场景
  • 大量历史数据的负荷、流量、气象等时序预测
  • 序列到序列任务（多步预测、轨迹）
建模步骤
  1. 归一化，滑动窗口构造样本（前 w 期预测后 1 期/多期）
  2. 严格按时间顺序划分，绝不能随机打乱
  3. 训练早停，反归一化，与 ARIMA/灰色同口径比留出期误差
要点与易错
  • 小样本上 LSTM 常输给灰色/ARIMA，必须做基线对比再决定是否使用
  • 多步预测区分"递归预测"与"直接多输出"，误差累积要讨论
论文策略：把神经网络作为"对比模型"或在简单模型残差大时引入，并说明数据量为何支撑网络训练；样本少于几百时优先统计模型，硬上网络会被质疑过拟合，反而扣分。

MODULE 10 · STATISTICS

10统计检验与数据预处理

所有数据题的"地基"：先清洗、再探索，用假设检验定量回答"两个变量有没有关系/有没有差异"。检验往往直接对应国赛问题（如 2022C 风化与类型是否有关）。点开卡片看统计量公式、判据与步骤。
出现频率：极高难度 ★★数据题第一问常客
数据清洗（无效/重复/逻辑矛盾）第 1 步高频▾按题目规则剔除无效样本、处理重复与逻辑冲突，清洗规则必须在论文中写明依据。
核心判据
有效性规则来自题意，如 2022C：各成分百分比累加和不在 85%-105% 的样本判为无效数据剔除
应用场景
  • 表格数据存在空行、重复录入、单位混用、约束矛盾（如年龄 200）
  • 题目明确给出数据有效范围或成分和约束
建模步骤
  1. 逐列看类型、取值范围、唯一值，列出数据质量问题清单
  2. 按题意定清洗规则，记录剔除条数与理由（论文给前后样本量）
  3. 重复样本去重，矛盾样本核实后保留或修正
要点与易错
  • 不能凭感觉删数据；每一次剔除都要有题目或统计依据并可复现。
缺失值处理补全高频▾先看缺失机制与比例再决定删或插补，方法选择直接影响后续模型，论文要交代。
核心方法
缺失率高（>40%）的列直接剔除；少量：均值/中位数（偏态用中位数）、众数（分类）、KNN/回归/多重插补（MICE）
应用场景
  • 问卷、监测数据零星缺失需要补全才能建模
  • 判断缺失是否随机（MCAR/MAR/MNAR），非随机缺失本身可能含信息
建模步骤
  1. 统计每列缺失率并可视化缺失矩阵
  2. 高缺失列删除；数值列按分布选中位数/均值，关系复杂用 KNN/MICE
  3. 插补后对比插补前后分布，避免引入偏差
要点与易错
  • 训练集上算插补统计量再应用到测试集，防止泄漏；时间序列用前后向填充或插值。
异常值检测离群点高频▾用统计或模型方法识别离群点，结合业务判断保留、修正或单独讨论，不静默删除。
核心公式
3σ：正态下 |x−μ|>3σ 为异常；箱线图 1.5IQR：超出 [Q1−1.5IQR, Q3+1.5IQR]；模型法：孤立森林、DBSCAN、One-Class SVM
应用场景
  • 传感器毛刺、录入错误、极端客户/交易识别
  • 异常本身就是研究对象（故障、欺诈、风险）
建模步骤
  1. 单变量用箱线图/Z 分数，多变量用马氏距离/孤立森林
  2. 回溯原始业务核实，区分"错误数据"与"真实极端"
  3. 错误则修正/剔除，真实极端则 winsorize 截尾或保留并做稳健分析
要点与易错
  • 直接删除所有异常点会丢失关键信息；处理方式要做敏感性对比。
标准化与归一化量纲统一高频▾消除量纲让指标可比、让距离/梯度类算法正确工作，不同算法对应不同变换。
核心公式
Z-score 标准化 z=(x−μ)/σ（聚类、SVM、神经网络、正则模型）；min-max 归一 x′=(x−min)/(max−min)（灰色、神经网络、需限定区间）；对数/Box-Cox 改善偏态
应用场景
  • 基于距离/核的算法（KNN、K-means、SVM、PCA）必须标准化
  • 神经网络输入、灰色预测、需要非负区间的方法用 min-max
建模步骤
  1. 训练集上拟合 μ、σ 或 min、max
  2. 用同一参数变换训练/测试/待预测数据
  3. 模型输出按需反变换回原量纲
要点与易错
  • 树模型对单调变换不敏感，一般不需标准化；全数据先标准化再划分=数据泄漏。
卡方独立性检验分类×分类高频▾定量判断两个分类变量是否有关联，数据题第一问"某因素与类别是否相关"的标准答法。
核心公式
列联表期望频数 E=(行和×列和)/n；统计量 χ²=Σ(O−E)²/E，自由度 df=(r−1)(c−1)，p<0.05 拒绝独立（即有关）
应用场景
  • 风化与否 × 玻璃类型/纹饰/颜色（2022C 问题一）
  • 性别/地区/渠道等分类变量间的关联判断、拟合优度检验
建模步骤
  1. 列列联表并算期望频数（E<5 格子超 20% 用 Fisher 精确检验）
  2. scipy.stats.chi2_contingency 得 χ²、p、自由度
  3. 显著时用标准化残差或 Cramér's V 说明关联强度与方向
要点与易错
  • 显著只代表"有关"不代表因果，也不表示线性相关；样本量极大时几乎都显著，要报效应量。
t 检验（含正态性前提）两组均值高频▾比较两组均值是否有显著差异；用之前先检验正态性与方差齐性来选对版本。
核心公式
单样本 t=(x̄−μ₀)/(s/√n)；独立两样本 t=(x̄₁−x̄₂)/合并标准误；正态性 Shapiro/K-S（p>0.05 视为正态）、方差齐性 Levene
应用场景
  • 实验前后（配对 t）、两组人群/工艺/方案均值比较
  • 回归系数、处理效应是否显著不为 0
建模步骤
  1. 先 Shapiro 检验正态、Levene 检验方差齐性
  2. 正态方差齐用标准 t，方差不齐用 Welch t，配对数据用配对 t
  3. 非正态用非参数 Mann-Whitney U / Wilcoxon
要点与易错
  • α=0.05 时大样本临界 1.96；不检验前提直接套 t 检验是常见硬伤。
方差分析 ANOVA多组均值中频▾比较三组及以上均值是否存在差异，显著后再做事后多重比较定位是哪两组不同。
核心公式
F=(组间均方 MSB)/(组内均方 MSE)，服从 F(k−1,n−k)；p<0.05 表示至少两组不同；双因素 ANOVA 可分析主效应与交互效应
应用场景
  • 多种工艺/地区/方案的指标均值比较
  • 同时考察两个因素及其交互作用（双因素）
建模步骤
  1. 检验正态、方差齐性前提
  2. f_oneway / 双因素模型得 F、p
  3. 显著后用 Tukey HSD 事后两两比较，画箱线图佐证
要点与易错
  • 反复做两两 t 检验会抬高一类错误，必须先 ANOVA 再事后比较；前提不满足换 Kruskal-Wallis。
相关分析 Pearson / Spearman连续变量关系高频▾量化两个连续变量线性/单调关系的方向与强度，配热力图，是选模型和查共线的依据。
核心公式
Pearson r=cov(x,y)/(σₓσᵧ)（双变量正态、线性关系）；Spearman ρ=秩次的 Pearson（不要求正态、单调即可）；|r|>0.8 强相关，同时看 p 值
应用场景
  • 找因变量的关键影响因素、判断自变量共线性
  • 非正态或有序变量用 Spearman/Kendall
建模步骤
  1. 画散点矩阵看关系形态（线性才用 Pearson）
  2. 算相关系数与 p 值，画相关性热力图标星号
  3. 结合业务解释方向，高相关自变量做去共线处理
要点与易错
  • 相关不等于因果；非线性关系（如 U 形）r 可能接近 0，散点图不能省。

11机理建模与数值方法

A 题常客：从物理/化学/几何规律出发列方程（守恒、传热、运动、扩散），再数值求解。机理模型最能体现功底，是高分论文的分水岭。点开卡片看方程形式、场景、求解与验证步骤。
出现频率：A 题高难度 ★★★★★传热/运动/扩散/排队/仿真
常微分方程 ODE 建模连续机理高频▾用变化率关系（守恒、牛顿定律、增长规律）列时间导数方程，数值积分求解，是种群、传播、冷却类题的核心。
核心公式
一般形式 dy/dt=f(t,y)，y(t₀)=y₀；典型：Logistic dy/dt=ry(1−y/K)；SIR：dS/dt=−βSI/N，dI/dt=βSI/N−γI，dR/dt=γI；牛顿冷却 dT/dt=−k(T−Tₐ)
应用场景
  • 种群/技术增长与饱和、传染病传播仓室模型、药物代谢
  • 物体冷却/升温、运动学、化学反应动力学、多仓室物料平衡
建模步骤
  1. 找守恒/变化率关系：单位时间增量=流入−流出+生成−消耗
  2. 定义状态变量与参数，写方程组和初值
  3. scipy.integrate.odeint/solve_ivp 数值求解，刚性方程用 Radau/BDF
  4. 画状态随时间曲线，求平衡点并分析稳定性
要点与易错
  • 每个方程都要能量纲一致；参数未知时用数据反演（见参数估计卡），不能凭空设定。
偏微分方程 PDE 与有限差分时空机理中频▾状态同时随时间和空间变化（传热、扩散、波动），离散网格用有限差分求解。
核心公式
热传导 ∂T/∂t=α∂²T/∂x²；扩散 ∂u/∂t=D∇²u；一阶差分 ∂u/∂x≈(uᵢ₊₁−uᵢ)/Δx，二阶 ∂²u/∂x²≈(uᵢ₊₁−2uᵢ+uᵢ₋₁)/Δx²；显式稳定条件 αΔt/Δx²≤0.5
应用场景
  • 炉温曲线、热防护（2020A、2018A）、污染物扩散、应力场
  • 稳态问题（∂/∂t=0）转为边值问题直接解线性方程组
建模步骤
  1. 由守恒律列 PDE，写清初始条件与边界条件（定温/绝热/对流）
  2. 网格离散，显式向前差分或隐式（向后/C-N，无条件稳定）
  3. 迭代求解时空场，加密网格验证收敛
要点与易错
  • 显式步长不满足稳定条件会发散；边界条件漏写或写错，解一定错。
机理参数反演（最小二乘）机理+数据高频▾机理方程形式已知但参数未知时，用观测数据非线性最小二乘反演参数并给置信区间。
核心公式
min Σ(yₖ−y_model(tₖ;θ))²；scipy curve_fit/least_squares（Levenberg-Marquardt/BFGS/信赖域）；θ 协方差矩阵开方得参数标准差与 95% 置信区间
应用场景
  • 传热系数、热时间常数、增长率、扩散系数等未知参数标定
  • 2020A：以测温点拟合过炉速度与各温区换热系数
建模步骤
  1. 固定机理模型，参数给物理合理的初值与界
  2. 多初值拟合防局部最优，报告收敛信息
  3. 参数代入回画拟合 vs 实测曲线，报 RMSE 与置信区间
要点与易错
  • 参数不可辨识（多组参数拟合同样好）时要固定部分参数或加正则；只给点估计不给误差是扣分项。
蒙特卡洛模拟随机仿真高频▾系统含随机因素、解析解难求时，按分布大量抽样重复实验，用频率估计概率与输出分布。
核心公式
大数定律：估计量随 N 收敛，标准误 ∝1/√N（精度提 10 倍需约 100 倍样本）；投点积分 I≈(b−a)·(落入次数/总次数)
应用场景
  • 风险概率、可靠性、期望收益、复杂高维积分
  • 排队/库存/调度系统仿真、灵敏度与最坏情景分析
建模步骤
  1. 为每个随机输入确定并拟合分布（K-S 检验）
  2. 固定随机种子，重复抽样 N 次运行确定性模型
  3. 统计输出均值、分位数、概率，画 N-均值收敛曲线
要点与易错
  • 分布不能拍脑袋，要用数据拟合+检验；不画收敛曲线无法证明结果稳定。
排队论服务系统中频▾用到达与服务的随机过程解析计算等待时间、队长、利用率，用于窗口、通道、服务器配置。
核心公式
M/M/1：到达率 λ、服务率 μ（λ<μ），利用率 ρ=λ/μ，平均队长 L=ρ/(1−ρ)，平均等待 Wq=ρ/(μ−λ)；M/M/c 有 c 个并行服务台
应用场景
  • 安检/收费/挂号窗口数设计、呼叫中心坐席、充电桩配置
  • 给定服务水平（平均等待上限）反推最少服务台数
建模步骤
  1. 用数据验证到达间隔、服务时间近似指数分布
  2. 选 Kendall 记号模型（M/M/1、M/M/c）
  3. 算性能指标，结合成本做服务台数优化，复杂情形转蒙特卡洛
要点与易错
  • 稳态公式要求 ρ<1 且系统运行足够久；分布不符合马尔可夫假设要用 G/G/c 仿真。
元胞自动机 / 系统动力学离散演化中频▾用简单局部规则/反馈回路演化出复杂全局行为，分别适合空间涌现问题和宏观反馈系统。
核心公式
元胞自动机：网格上元胞状态 Sᵢ(t+1)=F(邻居状态 S(t))，同步更新；系统动力学：存量 Level(t+dt)=Level+dt×(流入率−流出率)，含正负反馈回路
应用场景
  • 元胞自动机：人流疏散、交通流、火灾蔓延、舆情传播、城市扩张
  • 系统动力学：生态/人口/经济/供应链的存量流量反馈（Vensim 画流图）
建模步骤
  1. 元胞：定义网格、状态集、邻域（冯诺依曼/摩尔）、局部转移规则并迭代
  2. SD：画因果回路图与存量流量图，写速率方程，仿真并做政策情景
  3. 参数做敏感性，统计涌现指标（疏散时间、拥堵率）
要点与易错
  • 局部规则要有现实依据并做参数敏感性；元胞尺度/时间步选择影响结果，需网格无关性验证。
插值、拟合与数值积分数值基础A 题高频▾由离散观测点构造函数：插值必过每个点、拟合逼近整体趋势；据此补中间值、做光滑曲线或求面积/积分量，是 A 题与几何题的基础工具。
核心公式
拉格朗日插值 L(x)=Σᵢ yᵢ·ℓᵢ(x)；分段线性连接相邻点；三次样条 S(x) 分段三次且二阶导数连续，曲线更光滑
最小二乘拟合 min Σ(yᵢ−f(xᵢ))²（含噪声求趋势）；梯形积分 T=h·Σ(yᵢ+yᵢ₊₁)/2；辛普森积分 ≈ (h/3)(y₀+4y奇+2y偶+yₙ)
应用场景
  • 稀疏/缺失数据补点、由离散测点还原连续温度场/曲面、散点画等值线
  • 已知离散值求积分量：面积、平均温度、累计能量等（2020A、2018A 均用到）
  • 点精确无误差用插值，点含测量噪声用拟合，先判断再选择
建模步骤
  1. 判断数据是否含噪：无误差选插值、含噪选最小二乘拟合
  2. 一维用 scipy interp1d（linear / cubic）、CubicSpline；规则网格用 RegularGridInterpolator，散点用 griddata
  3. 积分用 numpy.trapz 或 scipy.integrate.simpson，并加密步长验证收敛
  4. 论文给出插值曲面/曲线与误差，说明边界外推的局限
要点与易错
  • 外推（超出已知 x 范围）不可靠；高次多项式在端点易振荡（龙格现象），优先分段低次或三次样条
  • 插值不是预测模型，不能代替回归/时序预测；高维稀疏时插值失真严重
差分方程与离散动力模型（阻滞增长 / SIR→SEIR）离散机理中频▾时间或空间天然离散（按天、按代、按格点）时，用相邻时刻递推描述增长与传播，迭代求解并分析平衡点稳定性。
核心公式
一阶线性差分 xₜ₊₁=a·xₜ+b；离散阻滞增长 xₜ₊₁=xₜ+r·xₜ(1−xₜ/K)，K 为环境容量
SIR 差分（N 不变）：Sₜ₊₁=Sₜ−βSₜIₜ/N，Iₜ₊₁=Iₜ+βSₜIₜ/N−γIₜ，Rₜ₊₁=Rₜ+γIₜ；SEIR 增加潜伏仓 E；基本再生数 R₀=β/γ
平衡点令 xₜ₊₁=xₜ 求 x*，稳定性判据 |f′(x*)|<1；R₀>1 疫情扩散、R₀<1 逐步消亡
应用场景
  • 按日/按代更新的传染病、谣言、技术、产品扩散（SIR/SEIR/Logistic）
  • 人口年龄结构演化（Leslie 矩阵）、分账期的经济/库存动态
  • 连续 ODE 不便解析时，用离散递推做数值机理仿真
建模步骤
  1. 画仓室/状态转移图，对每个状态列"流入−流出"的守恒递推式
  2. 由数据拟合或查文献定参数（感染率 β、恢复率 γ 等）
  3. 从初值迭代，画各仓室时间曲线与相图，求平衡点与 R₀
  4. 做参数敏感性，并与连续 ODE（odeint）结果互验
要点与易错
  • 步长太大会导致迭代发散或失真，需做步长收敛说明；各仓室之和必须守恒（恒等于 N）
  • 差分递推与微分方程不要混写，全文符号、时间下标保持一致
敏感性分析与鲁棒性验证验证必备高分关键▾系统改变参数、数据或假设，观察输出与结论是否稳定、哪些参数最关键，是补齐"验证不足"短板、证明结论可信的必做环节。
核心公式
单因素 OAT：参数 x 变动 Δx/x，输出弹性系数 S=(Δy/y)/(Δx/x)，常取 ±10%、±20%，画龙卷风图（tornado）按敏感度排序
多因素/全局：Morris 法、Sobol 指数（主效应+交互效应）；鲁棒性：数据加噪或 bootstrap 重采样、换权重/换模型对照，看排序或最优方案是否反转
应用场景
  • 评价题权重不确定：换 AHP/熵权权重区间看排名是否稳定（评价题几乎必做）
  • 机理参数有测量误差、优化解依赖约束、预测依赖训练样本时，验证结论稳健
  • 对应优秀论文"验证不足平均仅 2.04/4"的最直接提分点
建模步骤
  1. 列出全部不确定参数并给出合理波动区间与依据
  2. 先做单因素扰动 + 龙卷风图，锁定少数关键参数
  3. 对关键参数做多因素/全局分析；数据层做 bootstrap、模型层做替代模型对照
  4. 明确写出"参数在何区间内，最优方案/排名结论保持不变"
要点与易错
  • 不能只跑一组参数就下结论，也不能只扰动无关参数做样子；敏感性图要标基准值
  • 区分"数值小幅变化"与"结论发生反转"，后者才是致命问题，必须讨论
优秀论文实例：2020A 炉温曲线（机理题范式）由能量守恒建立一维稳态传热（热传导+热对流）微分方程组，分区域求定温区温度分布；降温段用牛顿冷却定律、分区域热时间常数；再以测温点数据用最小二乘拟合未知参数，数值结果精确到 129.0153℃、207.8417℃；后续优化用二分法、BFGS、蒙特卡洛积分。链路：机理方程 → 参数反演 → 数值求解 → 优化控制，是 A 题满分结构，详见 思路专题。
机理题验证四件套：量纲检查、极限情形（参数取 0/无穷是否回到常识）、数值收敛（加密网格/减小步长结果稳定）、与实测或文献参数对照。

二、通用破题五步法

  1. 读题定类型：题目核心矛盾是什么？评价排序 / 预测外推 / 优化决策 / 机理过程 / 分类聚类 / 路径几何 / 随机风险，先归到七类之一

  3. 逐问建模型链：每问写"选择依据两三句"：题意是什么结构 → 备选模型 → 为何选它；多模型之间写清接口变量
  4. 求解并留全证据：中间结果、参数、收敛过程全部留存；数值带单位；结果用表格
  5. 按题型做验证：预测做回测、优化查约束、机理查量纲收敛、随机查尾部、路径做回放，最后敏感性分析

1题目速览与小问矩阵

古代玻璃文物以石英砂为主体、以助熔剂区分类型：高钾玻璃用草木灰（K₂O 高，流行于岭南/东南亚），铅钡玻璃用铅矿石（PbO、BaO 高，楚文化特征）；埋藏中受风化会改变表面成分。题目要求分析风化规律、分类分亚类、鉴别未知物、分析成分关联。

小问输入输出（交付物）怎么算对（评价）模型
一问基本信息表 + 成分表风化与类型/纹饰/颜色关系；风化前后成分规律；风化前含量反推值p 值定量、反推误差 r 小、规律可解释卡方检验 + 逻辑回归 + 反演
二问一问清洗后的高钾/铅钡数据分类规律 + 每类亚类划分 + 合理性敏感性类间差异显著、轮廓系数高、改 k 稳定判别分类 + K-means
三问二问模型 + 未知样本表未知样本类别与亚类归属表复用模型、结果可复核、敏感性复用二问模型
四问分类后成分数据成分关联关系；两类玻璃成分差异相关系数显著、因子可命名Spearman + 因子分析

接口变量：一问输出"清洗后数据 + 风化校正"→ 二问据此分类；二问输出"判别式 + 亚类中心"→ 三问直接套用。模型链靠这些接口串起来，这正是优秀论文的共同特征。

2数据画像与预处理

  1. 有效性筛选：题目明确"各化学成分百分比累加和介于 85%-105% 为有效"，超出区间的样本整条剔除并在论文记录剔除条数（这是题目给的硬规则，必须用）
  2. 缺失处理：统计每列缺失率，高缺失成分列剔除；零星缺失用同类样本中位数或热卡填充（数值不服从正态，别用均值）
  3. 部位配对：同一文物的"未风化点/风化点"（部位 1/2）配对保留，用于风化前后对照
  4. 标准化：聚类、逻辑回归、因子分析都对量纲敏感，统一 Z-score；反演结果再反标准化回百分比
  5. 探索成图：按类型/风化分组画成分箱线图，先形成"哪些成分区分两类、哪些随风化变"的直观假设

3算法选型论证：为什么是这些算法

任务候选方法可行性与取舍结论
风化与类别是否有关卡方独立性检验两边都是分类变量，直接给 χ²、p 值与 Cramér's V 关联强度，可解释、评委认✓ 选用
逻辑回归能算但回答的是"预测概率"而非"是否独立"，杀鸡用牛刀且不给关联强度备选
直接看频数表只能描述、无法排除抽样偶然，缺定量判据✗ 不够
风化前成分反推逻辑回归 + 逆向反演有显式线性表达式与权重，可固定类型反解成分、能量化反推误差 r，可解释性最强✓ 选用
随机森林/SVM 反演精度可能高，但黑箱、无显式逆表达式，反演要再套优化，且小样本易过拟合✗ 不适合反推
分组均值直接减忽略成分间协变，无法控制类型变量，反推粗糙✗ 过简
亚类划分K-means类内做球形划分、速度快，肘部法+轮廓系数能证明 k 合理，便于敏感性分析✓ 选用
层次聚类样本少也能用、有树状图，但本题每类样本数十个，K-means 更易给中心与归属可作对照
DBSCAN本题簇近似球形、需要明确亚类标签，密度法反而会把边缘样本标成噪声✗ 不匹配
成分关联与差异Spearman + 因子分析成分比例多不正态，用秩相关稳健；因子分析先过 Bartlett/KMO，旋转后因子可现实命名✓ 选用
Pearson + PCAPearson 要求双正态、PCA 主成分只有数学方向不保证可命名，解释"两类差异"时偏弱对照即可
一句话选型逻辑：这道题的每个任务都要求"既要结果、又要可解释、还要能逆向/复用"，所以全程优先选有显式表达式、带统计判据的模型（卡方、逻辑回归、K-means+轮廓系数、因子分析），把随机森林、SVM、神经网络这类黑箱模型仅作为精度对照。数据量小（百件级）也决定了复杂模型没有优势。
如果换个条件，选型会怎么变？

· 若样本上千且成分与类别高度非线性：主模型可换梯度提升树 XGBoost，逻辑回归降为可解释基线；

· 若题目只要求"预测未知样本类别"不要求解释：SVM/随机森林可以直接上，但仍要交叉验证；

· 若亚类形状明显非球形：改用层次聚类或 GMM 并对比轮廓系数。

4逐问建模详解（含详细解题顺序）

问题一　关系判断 → 规律 → 反演，三步走
  1. 关系（卡方）：分别建"风化 × 类型""风化 × 纹饰""风化 × 颜色"三张列联表，chi2_contingency 得 χ²、p；p<0.05 判定有关，并用 Cramér's V 说强度。期望频数过小的表改 Fisher 精确检验
  2. 规律（逻辑回归）：以"是否风化"为 0/1 因变量、标准化成分为自变量，拟合 logit P(风化)=β₀+Σβⱼxⱼ；βⱼ 为正表示该成分随风化升高、为负表示降低，exp(βⱼ) 是优势比，据此逐条写规律
  3. 反演（逆向优化）：固定玻璃类型，以风化前成分为决策变量，使逻辑回归预测值与"未风化"目标的偏差 + 成分和=100% 约束最小：min r=|σ(β₀+Σβⱼx̂ⱼ)−0|，s.t. Σx̂ⱼ=100、x̂ⱼ≥0，用最小二乘/SLSQP 求解，r 越小反推越可信
logit：ln(P/(1−P))=β₀+β₁SiO₂+…+βₖK₂O；反演：min r，约束 Σx̂=100%
问题二　先分大类、再分亚类，双分析收尾
  1. 用问题一清洗后数据，以类型为标签建判别式（逻辑回归/LDA），交叉验证报训练/留一准确率，证明分类规律成立
  2. 在高钾、铅钡两类内部分别做 K-means：肘部法看 SSE 拐点、轮廓系数定 k（一般 2-3 个亚类），固定 random_state
  3. 合理性：画各亚类成分均值雷达/热力图，用 t 检验或方差分析证明亚类间关键成分差异显著
  4. 敏感性：改变 k、对数据加 5% 扰动、换初始化，看亚类中心与归属是否稳定，稳定才敢下结论
问题三　复用而非重建（最容易被忽略的得分点）
  1. 未知样本先过 85%-105% 有效性与缺失检查，同样标准化
  2. 直接套用问题二判别式定大类；再算到各亚类中心的距离定亚类
  3. 输出"样本编号 → 类型 → 亚类 → 归属概率/距离"的完整鉴别表，并对边界样本做敏感性说明

论文里明确写"本问复用问题二所建模型，未重新训练"，体现模型链接口意识，比另起炉灶更受评委认可。

问题四　相关 + 因子，讲清化学含义
  1. 先 Bartlett 球形度检验（p<0.05）与 KMO（>0.6）确认适合做相关/因子分析
  2. 算 Spearman 相关矩阵画热力图，围绕 SiO₂ 网络形成分解释（如 CaO 降粘度但过量析晶、Fe₂O₃ 影响分类与透明度）
  3. 因子分析按特征值>1 定因子数，方差最大旋转后按高载荷成分命名，比较两类玻璃在各因子上的得分差异

7论文写作要点

  • 摘要按问分段：每问一句"模型 + 方法 + 关键数值 + 结论"，如"采用卡方检验得风化与类型显著相关（χ²=…，p<0.05）；建立逻辑回归并反演，平均误差 r=…"
  • 问题重述要改写成自己的话并画出四问的模型链流程图，让评委一眼看到接口变量
  • 模型假设写清：成分和=100%、未测成分视为 0、样本具代表性，每条假设说明理由
  • 符号说明表统一全文记号（β、xⱼ、k、轮廓系数），正文不再临时定义
  • 每问固定四段式：问题分析 → 模型建立（含公式）→ 求解（含表/图）→ 结果分析与检验（合理性+敏感性）
  • 图表必带编号标题与单位，正文必须出现"如图 2 所示"的引用，不放无主图
  • 结论要回答案例问题：三问的鉴别结果做成正式表格，四问差异分点陈述，不写空话
摘要示范（一问，四要素齐全）"针对玻璃成分与表面风化的关联问题，本文先采用卡方检验确定表面风化与玻璃类型显著相关（χ²=…，p<0.05），与纹饰、颜色相关性较弱；经 85%-105% 有效性筛选与标准化后建立逻辑回归模型，求得 SiO₂、PbO 等成分权重，表明风化过程中 …… 含量上升、…… 下降；进而固定类型以预测误差最小为目标反演风化前成分，平均误差 r=…，为后续分类提供了校正依据。"

8可迁移套路

① 数据题第一问几乎固定为"统计检验定关系 + 描述统计找规律 + 预处理"；② 有监督分大类、无监督分亚类成对出现，聚类必配轮廓系数 + 敏感性；③ 后续问优先复用前问模型而非重建；④ 需要"反推/解释"时选有显式表达式的模型，黑箱模型只做精度对照；⑤ 每问都交代理由、数值、单位、一项验证。

1题目速览与小问矩阵

回焊炉分多个小温区，各温区设定温度不同，温区之间为间隙；电路板以恒定速度 v 过炉，焊膏温度随位置/时间变化形成"炉温曲线"。制程对升温斜率、恒温段时间、峰值温度等有上下限要求。

小问已知交付怎么算对方法
一问各温区设定温度、过炉速度、炉内测温点数据指定位置（温区中点/结束处）温度值与给定数据误差 <1℃稳态传热方程 + 参数反演 + 数值解
二问一问模型给定温区设定下的整条炉温曲线、制程指标曲线过约束、关键点温度精确瞬态 ODE 数值积分
三问制程约束（斜率/时间/峰值区间）满足约束的过炉速度上限/温区设定约束逐项满足、临界值精确二分法 / 约束求根
四问目标（如恒温区面积/时间最优）最优速度与温区温度组合目标更优、约束可行、稳健BFGS/遗传 + 数值积分

2物理图像：先把传热过程想清楚

  1. 分区域：沿炉道按温区/间隙切成若干段，定温区内部环境温度恒定，间隙区环境温度线性过渡，降温段无加热
  2. 定机制：炉内主要靠热对流（氮气环境，忽略辐射），电路板内部为一维稳态/瞬态导热，沿运动方向 x=vt 把空间问题转成时间问题
  3. 写守恒：单位时间电路板内能变化 = 对流换热量，由此得到一阶温度响应方程，每段引入热时间常数 τ 刻画升温快慢
  4. 衔接条件：分段交界处温度连续，作为下一段初值，逐段推进得到整条曲线
对流换热：q=hA(Tₐ−T)；能量守恒：ρcV·dT/dt=hA(Tₐ(t)−T)，即 dT/dt=(Tₐ(t)−T)/τ，τ=ρcV/(hA)

3算法选型论证：为什么必须机理先行

环节候选取舍结论
建立温度-位置关系守恒律传热微分方程参数物理可解释、可外推到未给工况、三四问优化必须靠它反复重算曲线✓ 主线
多项式/样条拟合测温点一问插值能过，但换温区温度/速度就失效，无法支撑优化问，属"只对一问"✗ 撑不起全题
神经网络拟合仅几十个测温点、且要外推，必过拟合且无物理约束，评委直接质疑✗ 禁用
未知换热参数非线性最小二乘反演机理形式已知、参数有数，curve_fit/least_squares 给点估计与置信区间、拟合误差✓ 选用
查表取经验常数与本题炉况不符、无法对齐测温数据，缺少"用题给数据"这一得分点✗
三问临界速度二分法求约束临界约束违反程度关于速度单调，二分收敛快、精度可控、结果可复现✓ 选用
网格穷举能做但慢、精度受步长限，论文显得粗糙对照
四问多变量优化BFGS/序列二次规划目标由数值积分给出、维数低（速度+少数温区温度），梯度类算法快而精；非凸处多初值✓ 选用
遗传算法全局稳但慢、结果有随机性，可作为非凸时的对照/兜底对照
核心判断：A 题的优化对象是"一条由物理规律决定的曲线"。只有先把传热机理建成可计算模型，三、四问改变速度/温区温度时才能重新算出曲线并判断约束与目标，这就是"机理模型是优化器内层的仿真器"。直接拟合只解决一问，做不了全题，这是机理题与数据题最本质的区别。

4逐问建模详解

问题一　分段传热建模 + 参数反演 + 关键点温度
  1. 按温区写出每段环境温度 Tₐ(t)（定温区常数、间隙线性、降温段按牛顿冷却），建立 dT/dt=(Tₐ−T)/τⱼ，τⱼ 为分段热时间常数
  2. 以题给测温点（时间-温度序列）为观测，未知参数 θ=(各段 τ、换热系数) 建最小二乘：min Σ(T_model(tₖ;θ)−Tₖ)²，用 least_squares（LM/BFGS）多初值拟合，报 RMSE 与参数置信区间
  3. 代入给定工况，solve_ivp 逐段积分，读取小温区 3/6/7/8 关键点温度（优秀论文结果 129.0153℃、163.9644℃、174.8322℃、207.8417℃，误差 <1℃）
问题二　整条炉温曲线与制程指标
  1. 以 x=vt 把过炉距离换算为时间，整段积分得到 T(t) 曲线
  2. 数值计算制程指标：最大升温斜率（差分）、各温度区间停留时间（指示函数积分）、峰值温度（max）
  3. 画曲线并把温区边界、约束上下限一并标出，直观验证
区间停留时间 t_[a,b]=∫ 1{a≤T(t)≤b} dt；峰值 Tmax=max T(t)；斜率 dT/dt 数值差分取最大
问题三　求满足制程约束的临界参数（二分）
  1. 把"是否满足全部制程约束"写成关于速度 v 的布尔函数 g(v)（内层调用问题二的曲线计算）
  2. 分析单调性后二分 v：g 为真一侧与为假一侧不断夹逼，容差取 1e-4，得临界速度
  3. 回报临界工况下的曲线与各项约束裕度，证明刚好卡在边界且不违反
问题四　机理模型外层套优化
  1. 决策变量：过炉速度 v + 可调温区温度；目标：如最大化产能（v 最大）或最小化温度曲线相对理想区间的偏差面积 ∫|T−T*|dt（数值积分/蒙特卡洛积分）
  2. 约束：升温斜率、各段时间、峰值温度上下限、温区温度调节范围
  3. SLSQP/BFGS 求解，多初值防局部最优；对最优解做参数 ±扰动的敏感性与可行裕度分析

7论文写作要点

  • 机理推导要完整：从能量守恒一步步到 dT/dt=(Tₐ−T)/τ，配示意图（温区分段、换热方向），让评委看到物理而不是套公式
  • 参数反演单列一节：给拟合前后对比、RMSE、参数置信区间，说明"参数来自题给数据而非假设"

  • 验证四件套不能少：量纲检查、极限情形（v→0 曲线趋近环境温度）、步长/网格收敛、与实测对照
  • 优化问写清决策变量、目标、约束三要素，并说明为何选二分/SLSQP，给多初值结果一致性
  • 摘要数值密集：机理名 + 反演方法 + 四个关键点温度 + 最优参数，全部带单位

8可迁移套路（A 题通用）

① 机理先行，不建机理直接拟合/优化是典型低分写法；② 未知参数一定用题给数据反演并报误差与置信区间；③ 把机理模型封装成"输入参数→输出曲线/指标"的仿真器函数，求根与优化都反复调用它；④ 验证做量纲、极限、收敛、实测四件套；⑤ 优化问在机理外层加决策变量与约束，结果精确、带单位、做敏感性。

1题目速览与小问矩阵

企业每周向多家供货商订货，供货商供货能力、历史供货量、供货稳定性不同；原材料有损耗率，需要经过 forwarder 转运。要在满足每周产能需求的前提下，安排 24 周"向谁订、订多少、找谁运"，兼顾供应稳定、成本低与产能提升。

小问核心任务交付关键模型
一问评价供货商重要性，确定最重要的若干家供货商评分与排名表多指标评价（熵权/TOPSIS）
二问选供货商并订 24 周订购方案，满足产能24 周订购量矩阵混合整数规划（单目标）
三问加入转运方案与损耗，订购+转运联合优化订购矩阵 + 转运矩阵多目标规划 + 遗传算法
四问新方案/产能提升情景新方案与差异对比复用模型 + 情景对比

接口变量：一问输出"入选供货商名单与权重"作为二、三问的可行集合；二问输出订购量作为三问转运的输入。评价不是终点，而是优化的前置过滤器。

  1. 供货能力：由历史 5 年供货量统计均值、峰值、供货周次占比（履约率）
  2. 供货稳定性：供货量变异系数 CV=σ/μ、连续断供次数、订单满足率
  3. 经济性：原材料损耗率、到厂价格/转运成本
  4. 把上述指标做正向化（成本型、区间型统一为越大越优）+ 标准化，形成评价矩阵；时间序列部分看供货的周期性与趋势

4逐问建模详解

问题一　熵权-TOPSIS 评价供货商
  1. 构建评价指标：供货量均值、履约率、稳定性（−CV）、低损耗率，全部正向化后标准化
  2. 熵权：算比重 pᵢⱼ、熵值 eⱼ=−kΣp ln p、差异系数 dⱼ=1−eⱼ、权重 wⱼ=dⱼ/Σd
  3. TOPSIS：加权矩阵 → 正/负理想解 Z⁺、Z⁻ → 贴近度 C=D⁻/(D⁺+D⁻)，按 C 排名取前若干家
熵权 wⱼ=(1−eⱼ)/Σ(1−eⱼ)；TOPSIS 贴近度 Cᵢ=Dᵢ⁻/(Dᵢ⁺+Dᵢ⁻)，C 越大越优
问题二　单目标混合整数规划
  1. 决策变量：xᵢₜ 第 t 周向供货商 i 的订购量（连续）；yᵢ 是否选用（0-1）
  2. 目标：最小化总采购/缺货成本（或最大化满足率），Σᵢₜ cᵢxᵢₜ + 缺货惩罚
  3. 约束：每周有效供给（扣损耗）≥ 产能需求；xᵢₜ≤产能上限·yᵢ；最少/最多选择家数；非负与整数
  4. 求解输出 24 周×供货商订购矩阵，校验每周约束是否满足
min Σ cᵢxᵢₜ；s.t. Σᵢ (1−lossᵢ)xᵢₜ ≥ demandₜ，xᵢₜ≤M·yᵢ，Σyᵢ≤N，x≥0，y∈{0,1}
问题三　加入转运的多目标联合优化
  1. 新增 zᵢⱼₜ 由 forwarder j 转运的量，补转运能力与成本约束
  2. 三目标：f1 供应稳定（断供/缺货最小）、f2 成本最低、f3 产能/满足率最高；先归一化再加权，或用 ε-约束求 Pareto 前沿后选折中解
  3. 变量规模大、含整数，用遗传算法：染色体编码"订购+转运方案"，约束用惩罚函数，交叉变异迭代，多次运行取稳定解
  4. 与贪心基线、问题二方案对比，证明联合优化更优
问题四　情景复用

产能目标变化=只改需求约束右侧常数，模型结构不变，重解后对比订购/转运量差异与成本变化，做需求 ±10% 的敏感性，体现模型可复用。

2主线：一条散热约束的四次演化

问题一 基础热平衡加翅片→问题二 换热面积可设计选材料+深度→问题三 材料与压力约束潮汐季节→问题四 环境随时间波动

核心不等式始终是"总产热 ≤ 总散热"：N·P_server ≤ h·A(Tₛ−T_water)。每一问只是在 A（换热面积）、h（换热系数，随材料/水流变）、T_water（海水温度，随季节潮汐变）和耐压约束上增加可设计维度。看懂这条主线，就不会把五问做成五张皮。

热平衡：N·Q ≤ h·A·ΔT；圆柱换热 A=πDL+2π(D/2)²；加 n 片翅片后 A=A₀+n·2π(r²−(D/2)²)；耐压 D≤2[σ]t/p(depth)

4逐问建模详解

问题一　两个上界取小
  1. 空间上界：圆柱内部按三种服务器排列方式算可容纳数，取最大排列得 465
  2. 散热上界：稳态 N·Q=hAΔT，氮气内部只计热对流，代入得 119
  3. 瓶颈是散热，取 min=119；论文要说明"为什么散热先成为瓶颈"
问题二　翅片整数规划
  1. 决策变量：服务器数 N、翅片数 n（整数）；翅片占内部/外部空间，写空间约束
  2. 目标 max N；约束：产热≤增大后的散热（A 随 n 增）、几何不重叠、翅片间距下限
  3. 求解得 N=401、n=168，并做翅片数-数量曲线说明边际收益递减
问题三　熵权选材 + 深度优化
  1. 先按硬约束剔除不适用材料（如抗腐蚀不达标），剩余材料做熵权-TOPSIS 排序
  2. 深度 d 影响海水温度（更冷利于散热）与壳体承压（越深要求壁厚/强度越高），建立 N(d) 与耐压约束
  3. 联合优化材料与深度，得 AISI 1040、600m、423 台，做深度敏感性
问题四　时序拟合 + 保守情景
  1. 潮汐水位/水温用 T(t)=T̄+A·sin(ωt+φ) 最小二乘拟合，报振幅、相位与拟合误差
  2. 工程取保守：用每月最高水温 + 最低水位（散热最差组合）算可容纳数量
  3. 输出 24 小时/12 个月数量曲线，得最不利月（7 月 409 台）作为安全配置
问题五　建议信（开放写作）

每条建议都挂一个前文数值：排列方式（问题一）、翅片数量（问题二）、材料与下潜深度（问题三）、季节运维冗余（问题四）。格式为正式信函，先结论后依据，不写无数据支撑的空话。

① TOPSIS（NumPy） 原理 ↑

python
import numpy as np
def topsis(X, w=None):                       # X 已正向化, 行=对象 列=指标
    Z = X / np.sqrt((X**2).sum(axis=0))      # 向量标准化
    if w is not None: Z *= np.array(w)       # 加权(AHP/熵权/CRITIC)
    zb, zw = Z.max(0), Z.min(0)
    Dp = np.sqrt(((Z-zb)**2).sum(1)); Dm = np.sqrt(((Z-zw)**2).sum(1))
    S = Dm/(Dp+Dm)
    return S, np.argsort(-S).argsort()+1     # 得分, 排名

② AHP（判断矩阵 + 一致性检验 + 三种权重） 原理 ↑

python
import numpy as np
RI = [0,0,0.52,0.89,1.12,1.26,1.36,1.41,1.46,1.49,1.52]
def ahp(A):
    n = A.shape[0]
    w_arith = (A/A.sum(0)).mean(1)                       # 算术平均法
    gm = np.prod(A,1)**(1/n); w_geom = gm/gm.sum()      # 几何平均法
    val, vec = np.linalg.eig(A)                         # 特征值法
    lam = val.real.max(); w_eig = vec[:,val.real.argmax()].real
    w_eig /= w_eig.sum()
    CI = (lam-n)/(n-1); CR = CI/RI[n-1]
    assert CR < 0.1, f"一致性不通过 CR={CR:.3f}, 请调整判断矩阵"
    return (w_arith+w_geom+w_eig)/3, CR                 # 三法平均, CR

def entropy_weight(X):                    # X 已 min-max 归一到 [0,1]
    X = X + 1e-9                          # 非负平移防 ln0

⑨ 灰色预测 GM(1,1) 原理 ↑

python
import numpy as np
def gm11(x0, predict=3):
    x0 = np.array(x0,dtype=float); n=len(x0)
    x1 = np.cumsum(x0)                                  # 1-AGO
    z1 = 0.5*(x1[1:]+x1[:-1])                          # 紧邻均值
    B = np.c_[-z1, np.ones(n-1)]; Y = x0[1:]
    a, b = np.linalg.lstsq(B, Y, rcond=None)[0]        # 发展系数, 灰作用
    k = np.arange(n+predict)
    hat = (x0[0]-b/a)*np.exp(-a*k)+b/a                 # 累加预测
    pred = np.r_[hat[0], np.diff(hat)]                # 累减还原
    return a, b, pred

绘制五步法：

  1. 先按小问纵向分块：每一问一个泳道，写清"输入数据 → 处理方法 → 模型 → 输出"；
  2. 方框只写方法名+关键动作（如"熵权法定权"），不堆公式，一框不超过 12 字；
  3. 箭头只表示两种关系：数据流（实线 →）和反馈/迭代（虚线 ⇢），全图统一；
  4. 同一层级方框等大、等距、左对齐或居中对齐，用网格吸附避免错位；
  5. 配色不超过 3 种：主色填关键模型框、灰框装数据/结果，导出 300dpi 或矢量 SVG。

原始数据→预处理→模型一→模型二→结论

问题一·评价→汇总←问题二·优化

③ 闭环迭代：含参数反演、模型检验与修正（机理题、预测题常用）

代码报错与异常结果排查手册

比赛三天里最浪费时间的不是不会建模，而是环境报错和"结果不对劲却找不到原因"。下面按环节整理高频问题，每张卡点开是「为什么 → 怎么改 → 怎么预防」。先看最后一组"结果异常"，那比直接报错更隐蔽。

一、环境与安装

ModuleNotFoundError: No module named 'xxx'▾装了库却导不进，多半是多环境/装错解释器。
原因与解决
  • pip 装到了别的 Python：先 import sys;print(sys.executable) 看当前解释器，再用 python -m pip install xxx 装到同一环境
  • 库名与导入名不同：scikit-learn 导入名是 sklearn、yaml 对应 PyYAML、pymoo 导入 pymoo
  • 公司/校园网受限：加国内镜像 -i https://pypi.tuna.tsinghua.edu.cn/simple
预防
  • 赛前一周就把环境装好并跑通一遍，把 pip list 导出 requirements.txt 备份，比赛断网也能离线安装 wheel
中文路径 / 文件找不到 FileNotFoundError▾路径含中文、空格或反斜杠转义导致读不到文件。
原因与解决
  • Windows 路径用原始字符串 r"D:\建模\data.xlsx" 或正斜杠 "D:/建模/data.xlsx"，避免 \t \n 被转义
  • 用 os.path.exists 先确认；读取 Excel 指定引擎 openpyxl：pd.read_excel(f, engine='openpyxl')
  • 文件名别用空格和特殊符号，数据统一放 data 子文件夹

二、pandas 数据处理

SettingWithCopyWarning：切片赋值无效▾在筛选结果上改值，原表没变还报警。
解决
  • 链式索引 df[df.x>0]['y']=1 是错的；改成 df.loc[df.x>0,'y']=1
  • 需要副本先 df2=df[cond].copy() 再改，明确意图
KeyError: '某列名' / 列里全是 NaN▾列名有隐藏空格、全半角差异或类型没转对。
解决
  • 先 print(df.columns.tolist()) 看真实列名，统一 df.columns=df.columns.str.strip() 去空格
  • 数字列读成 object（混入空格/逗号/"-"）：pd.to_numeric(s, errors='coerce') 强转，非法变 NaN 再处理
  • 缺失填补分类型用众数、数值用均值/中位数/插值，并记录填补方式写进论文
merge/concat 后行数暴增或对不上▾连接键有重复或一对多被笛卡尔放大。
解决
  • 连接前 df.key.duplicated().sum() 检查键是否唯一，明确用 inner/left/outer 哪种
  • 一对多是正常的，多对多才会爆炸；先聚合到同一粒度再连

三、numpy 与数值计算

Singular matrix / LinAlgError 矩阵奇异▾求逆或解方程组时矩阵不可逆，常见于共线/相关列。
解决
  • 别用 np.linalg.inv，改最小二乘 np.linalg.lstsq 或伪逆 pinv，数值更稳
  • 根因多是自变量完全相关（如同时含总分和分项）：删冗余列、做 PCA，或改用岭回归
divide by zero / overflow / 结果 inf、nan▾分母为 0、log 了 0 或数值上溢。
解决
  • 分母加极小值 eps=1e-9；熵权里概率为 0 时规定 0·ln0=0，用 np.where 或先 clip
  • exp 上溢改 sigmoid/logsumexp 稳定写法；归一化前先排查异常大值

四、sklearn 机器学习

Expected 2D array, got 1D▾单个特征或单条预测时维度不对。
解决
  • X 必须二维：X=df[['列名']]（双括号）或 X.values.reshape(-1,1)
  • 预测单条也要二维：model.predict(np.array([[x]]))
NotFittedError / 结果每次都变▾没 fit 就 predict，或没固定随机种子。
解决
  • 流程必须 model.fit(X_train,y_train) 后再 predict；用 Pipeline 把预处理和模型串起来防漏
  • 固定随机种子保证可复现：random_state=42 同时设在 train_test_split、KMeans、随机森林
ConvergenceWarning 收敛警告▾迭代次数不够或数据没标准化。
解决
  • 先 StandardScaler 标准化（距离/梯度类模型必需），再增大 max_iter
  • 逻辑回归/SVM 不收敛多是尺度问题或 C 过大；标准化后仍不收就检查标签是否两类都有
信息泄漏：测试集表现异常好▾标准化/特征选择用了全量数据，把测试信息泄漏进去。
解决
  • 所有 fit 只在训练集：scaler.fit(X_train)，再 transform(X_test)，用 Pipeline 自动保证
  • 交叉验证内做预处理，不能先对全数据标准化再划分

五、优化求解

问题不可行 Infeasible / 无界 Unbounded▾约束互相矛盾，或漏了关键约束。
解决
  • 不可行：逐条放松约束定位冲突（常见需求>产能、上下界写反、等号过强），检查单位是否一致
  • 无界：漏了非负约束 x≥0 或缺产能/资源上界；决策变量边界要写全
  • 用 linprog 时注意它默认最小化，最大化要取负号；约束 Aub @ x ≤ bub 方向别反
非凸问题每次结果不一样▾单初值卡在不同局部最优。
解决
  • scipy.minimize 多组初始值取最优；或换 GA/PSO 全局搜索并画收敛曲线
  • 论文里报告"多次运行最优值/均值/方差"，体现稳健，而非只报一次偶然结果
Gurobi 报 license / 规模受限▾未装授权或超出免费规模。
解决
  • 学生可申请教育版；临时替代用开源 pulp(CBC)、ortools，接口改动很小
  • 启发式（scikit-opt、pymoo）不依赖商业求解器，大规模非凸更稳

六、时序与统计

差分后 ADF 仍不平稳 / ARIMA 不收敛▾差分过度、季节性没分离或阶数过高。
解决
  • 差分一般不超过 2 阶；有季节周期先拆季节（SARIMA 的 s 或 STL 分解）
  • 定阶用 ACF/PACF + AIC，p、q 从小往大试；样本太少（<20）直接换灰色/指数平滑
p 值是 NaN 或检验报错▾样本太小、某组无方差或列联表期望频数过低。
解决
  • 某组所有值相同则无方差，无法做 t/ANOVA；卡方期望频数<5 改用 Fisher 精确检验或合并类别
  • 检验前先 describe() 看各组样本量与方差，别机械套检验

七、matplotlib 绘图

中文显示成方块、负号变问号▾默认字体不含中文。
解决
  • 开头统一设置：plt.rcParams['font.sans-serif']=['Microsoft YaHei','SimHei']；plt.rcParams['axes.unicode_minus']=False
  • savefig 后再 show；先 savefig 再 show 可避免存出空白图；bbox_inches='tight' 防标签被裁

八、结果不对劲（最隐蔽，优先排查）

分类准确率虚高（如 97% 但没意义）▾类别极不平衡，全猜多数类也高。
解决
  • 看混淆矩阵、召回率、F1、AUC 而非只看 accuracy；用 class_weight='balanced' 或 SMOTE
  • 和"全猜多数类"的基线比较，模型必须明显优于基线才算有效
预测值几乎全相同 / R² 为负▾特征无解释力、没标准化，或测试集分布漂移。
解决
  • R² 为负说明还不如直接用均值预测：检查特征相关性、是否漏关键变量、量纲是否压制系数
  • 先跑线性基线，再逐步加复杂模型；时间序列注意不能随机划分，要按时间切分
K-means 每次分群结果不同▾随机初始化 + 没标准化。
解决
  • 先 StandardScaler；设 random_state、n_init=10 取最优；用 k-means++ 初始化
  • 用肘部法+轮廓系数定 K，并对结果稳定性做多次验证
优化/仿真结果明显违背常识▾单位、方向或约束写错。
解决
  • 做量纲检查和极限测试（参数取 0/极大是否回到常识）；用一个手算小例子验证代码
  • 成本型指标是否做了正向化、最大化最小化是否取反、百分比和小数是否混用，逐项核对
通用排查顺序：先让数据"可见"（打印 shape、dtypes、head、describe）→ 用最小样例手算对照 → 自底向上逐段验证中间结果 → 最后才怀疑模型。把每步中间结果存成 csv 或打印，比盯着最终错误调试快得多。

假设检验：p<0.05 显著；F 看方程整体、t 看单变量、卡方看分类变量独立、ANOVA 比多组均值
回归：R²越近1越好；VIF>10 共线；残差应白噪声
预测误差：RMSE=√(Σ(y−ŷ)²/n)，MAPE=均值|(y−ŷ)/y|，可跨量纲比较
聚类：轮廓系数∈[−1,1]越大越好；时序：ADF p<0.05 平稳；传播：R₀=β/γ，>1 扩散
蒙特卡洛误差量级 1/√n（精度×10 需样本×100）
